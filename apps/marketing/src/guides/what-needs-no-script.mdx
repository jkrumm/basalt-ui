Most of a content page is HTML. Each part below carries the mark of what it ships: <ModeTag mode="static" /> is HTML and CSS only, <ModeTag mode="enhanced" /> works as HTML and gains behavior in an island, and <ModeTag mode="island" /> needs its script. This page is built from the first kind, and ships no JavaScript beyond the head script every page carries.

## Stat cards <ModeTag mode="static" />

A dashboard's cards render at build time, sparklines included. The picture is drawn at rest, so nothing hydrates.

<HeroConsole />

A strip of figures is the same: one surface, a sparkline in a cell, no script.

## Tables <ModeTag mode="static" />

A table of plain data is a native table with numbers and dates formatted by the shared formats. `interactive` is what makes it <ModeTag mode="enhanced" />: the same HTML first, sorting and paging once it hydrates (see [Islands in MDX](/guides/islands-in-mdx/)).

## Tabs <ModeTag mode="static" />

Tabs are platform markup: an ARIA tab list and its panels. The head script every page carries switches them; without it every panel shows under its name.

<Tabs label="Install with" tabs={['bun', 'npm', 'pnpm']}>
  <Tab label="bun">`bun add basalt-ui`</Tab>
  <Tab label="npm">`npm install basalt-ui`</Tab>
  <Tab label="pnpm">`pnpm add basalt-ui`</Tab>
</Tabs>
