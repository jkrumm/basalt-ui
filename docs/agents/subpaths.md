# basalt-ui subpaths: full purpose of each

## Subpath ownership

| Subpath                  | Layer         | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------------ | ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `basalt-ui`              | ui            | The app root and the state seams: `BasaltProvider`, `IntlScope`, `setScheme`, `setAppearance`, `persisted`, `notify`, `externalField`, `useNow`, `createFormat`, `useFormat`, and the port types every subpath names (`NavTarget`, `LinkComponent`, `IconComponent`, `FieldLike`, `DetailHost`, `DragLike`). Reaches no peer beyond react.                                                                                                                                                                                                                                                                                                                                                                        |
| `basalt-ui/charts`       | headless      | CartesianChart (the TanStack Charts rung), the Lines, Bars, Sparkline, Heatmap, BandStrip and IntervalTrack kinds, ChartCard, the shared chartCursor and the geometry seam: useChartFocus (focus, dim the rest, one bound readout) and chartLabels (server-equal label width and placement) (no React UI library; @tanstack/charts + d3-scale peers)                                                                                                                                                                                                                                                                                                                                                              |
| `basalt-ui/tokens`       | headless      | BASALT token refs, buildPaletteCss, defineSeries, seriesTokens, groupTokens, alpha, the motion scale (MOTION_DURATION, MOTION_EASE_STANDARD, MOTION_EASE_ENTER, MOTION_EASE_EXIT, MOTION_SPRING, MOTION_STAGGER, staggerDelay)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `basalt-ui/vite`         | build-tooling | basalt(opts) — v3 plugin: peer and seed build gates, eject aliases, `.basalt/sources.css`, theme script, theme-color and manifest                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `basalt-ui/table`        | ui            | `DataTable` over `useDataTable`, the `col` kind columns, the parts `DataTable` composes (`TableToolbar`, `DataTableBody`, `TablePager`, `BulkBar`) and `tableCodec`, on TanStack Table v9 and `ui/*` primitives                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `basalt-ui/content`      | ui            | Markdown (react-markdown + remark-gfm + rehype-sanitize + remend, all required peers, every import static so server, client and hydrate render the same tree; `contentTrust` is REQUIRED and independent of `streaming`, which is a rendering mode only — render agent or model output with `contentTrust="untrusted"`: no `<img>` (alt text; `images="same-origin"` admits relative srcs), links limited to same-origin, https:, mailto: and tel:, and no `sanitize` or `rehypePlugins`; `contentTrust="trusted"` takes `sanitize` ({ allowTags, allowAttrs } additions over a fixed policy that runs last) and `rehypePlugins`; a missing or unknown `contentTrust` renders as untrusted) — the content surface |
| `basalt-ui/controls`     | ui            | The control tier (docs/v3/concepts/controls-url-state.md). Exports: `FilterSet` (a list of `spec(...)`s as one nowrap row of pills, a measured +N fold and the mobile Filters (n) sheet), `ViewTabs` bound to a control handle, `ControlView`, `ControlHome`, `filterSlot`, `spec`, and the v3 forms `FormField`/`FormRow`/`FormFooter`/`useFormDraft`/`toSubmitErrors`. The home picks the presentation (pill, row, inline), never a prop. Every control owns its own desktop/mobile swap in CSS and resolves with only its own peers.                                                                                                                                                                           |
| `basalt-ui/router`       | headless      | v3 router bridge — defineNav, field handles, navTarget, routerDefaults and the re-exported BasaltProvider on TanStack Router                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `basalt-ui/data`         | headless      | v3 data layer — query client, unwrap, optimistic and live queries on TanStack Query                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `basalt-ui/form`         | ui            | basalt's form parts bound to TanStack Form through createFormHook: useAppForm (FormField on every AppField, Form and Footer inside AppForm, blur-then-change revalidation by default), withForm                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `basalt-ui/page`         | ui            | v3 page composites — Page, PageBar, PageAside, Section, SplitPage, InnerNav, QueryState, overlays, and the article parts (Prose, Callout, Toc, ArticleLayout)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `basalt-ui/cards`        | ui            | v3 card composites — StatCard, StatGroup, BarList, EventList, RowList, RelationshipCard, StepRail, ChainView, Board, FlowCanvas, FlowChecklist, useFlow                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `basalt-ui/motion`       | ui            | v3 motion presets — useMotionPreset and motionPreset (overlay, item, card) on motion/react, collapsed under reduced motion                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `basalt-ui/ai`           | ui            | v3 AI-chat part views — partView, defineBlock, defineCatalog                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `basalt-ui/ui/*`         | ui            | v3 primitives — one module per primitive on Base UI, wildcard entry; a guard, a test helper and the slot table do not resolve                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `basalt-ui/core/*`       | ui            | The modules an ejected primitive imports (cn, format, messages, phase, ports, list, …), each listed in the exports map and held to the seeds by a test; every other core module is unpublished, and no public type lives here                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `basalt-ui/shell`        | ui            | App shell — AppShell, the CSS-grid frame: header, rail, one scrollport, aside and phone tab bar from one defineNav; defineCommands chords run on TanStack Hotkeys                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `basalt-ui/lint`         | build-tooling | v3 oxlint plugin — tooling, no app bundle                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `basalt-ui/stylelint`    | build-tooling | v3 stylelint preset — tooling, no app bundle                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `basalt-ui/testing`      | build-tooling | v3 test harness — renderApp, settled, quality; tooling, no app bundle                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `basalt-ui/theme-script` | build-tooling | v3 pre-paint color-scheme script, frozen per major                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `basalt-ui/static`       | ui            | Content-site parts that render to static HTML with no client JavaScript: no provider, context, hook or router, every label a prop (Prose, SiteArticle, SitePager, SiteCallout, SiteCodeBlock, SiteTabs, SiteTab, SiteForm, SiteField, SiteSubmit, SiteDataTable, SiteHeader (links and menus), SiteFooter, ThemeSwitch, siteMdxComponents) and the landing blocks (SiteHero, SiteBento, SiteFeature, SiteComparison, SiteQuestionList, SiteCallToAction); the site profile                                                                                                                                                                                                                                        |
| `basalt-ui/astro`        | build-tooling | basaltAstro() Astro integration — Tailwind 4, static.css on every page, the three faces through the Astro Fonts API and the head scripts; the site profile                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

Also published, but not JS subpaths: `basalt-ui/styles.css` (the one stylesheet: `@layer basalt;`, the three font imports, then basalt's own layer), the v3 CSS entries `basalt-ui/{tokens,typography,prose,fonts,tailwind,static,starlight}.css`, the Astro head component `basalt-ui/astro/BasaltFonts.astro`, the two MDX island tags `basalt-ui/astro/mdx/{Chart,DataTable}.astro` and `basalt-ui/configs/*` (raw oxlint / tsconfig / lefthook / oxfmt presets).
