## 5. PALANTIR / BLUEPRINT PRINCIPLES TO ADOPT

1. **Three-tier placement law**: page header = nav/tabs/global settings (≤5 primary actions, persistent, never scrolls); section header = that section's actions + count; widget = only its own display/formatting (Workshop best-practices).
2. **Actions sit next to what they act on** — a button's reach decides its home; if it affects more than one input it is promoted from InputGroup to ControlGroup (Blueprint `control-group.mdx`).
3. **Filters are state, not widgets**: one filter store emits filter state, downstream charts/tables consume filtered data and never own filters; defaults live on the filter variable (Workshop Filter List) → maps to `createSearchParamStore` + `linkSearch`.
4. **Filter layout is binary**: Vertical (left column, multi-filter analysis) vs Pills (compact horizontal, popover per pill) — pick per page, not per widget.
5. **Tabs are stateless**: selection derives from route/variable, never internal state (Workshop Tabs) — every tab control reads the URL.
6. **SegmentedControl ≠ ButtonGroup**: selection UI with reduced weight for views/filters; ButtonGroup with one cascaded intent for actions (Blueprint).
7. **One primary intent per group**; secondaries gray/minimal or folded into a menu / two-part button; never colour every button.
8. **Section = Card with elevation ≤1, `title`/`subtitle`/`icon`/`rightElement`(margin-left:auto)/`collapsible`/`compact`; header renders only when `title` exists** (Blueprint `section.tsx`).
9. **Counts on every table/list**, as a Tag in the section header (Workshop Metric Card Tag layout).
10. **≤10 visible components per view, 30–40% whitespace, Compact padding default** — encode as guards/tokens, not prose.
11. **One shaded/background container level per page**; containers separate groups, dividers separate related content within a group.
12. **No horizontal scrolling inside sections** (page-wide only); tables fit columns — directly indicts `.pageActions { overflow-x:auto }`.
13. **Touch targets ≥30px inside scrollable regions** — indicts `size="xs"` (≈22px) header controls.
14. **Overlays for temporary/secondary interaction only**; detail via collapsible panels so layers stay comparable; selection precedes action.
15. **Density ladder from a 4px base**: control heights 20/24/30/40, navbar 50, section header 50/40 compact, icons 16/20 — the model for basalt's missing header/section control tier.
16. **Mobile is unspecified upstream** — basalt must define the stacking rules itself (left filter column → top Pills row; vertical header → icon rail; Pills → Select/overflow menu).
