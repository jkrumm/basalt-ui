## 2. The thesis, and what discovery changed

**The move stands on the owner's reason: we want to own and restyle every implementation.** Mantine works for us without working with us. Obsidian's 14 `!important`, shutterflow's `.mantine-AppShell-header` DOM query and basalt's own 60 `:global`/Mantine selectors exist because we fight a frame we do not own. [Primitives](concepts/primitives-distribution.md) and [shell](concepts/shell-nav-router.md) put every class string, variant, slot and default in `src/ui`.

**A library swap alone would ship the same friction.** Argo's 234-row ledger says what else must change, and the count of Mantine rows only says that our own API must improve too (buckets below; 3 rows carry none). The 13 Mantine rows are already closed or fixed in 2.x, so G5's acceptance is a disposition per row ([migration 6.5](concepts/migration-release.md)), never "the port compiles".

## 3. Layers

```text
app          src/**  app composites, fully linted, on everything published
L5 tooling   vite  lint  stylelint  testing  cli                        no app bundle
L4 composites page  shell  cards  controls  table  charts  content  ai
             declared edges only: shell -> page, router;  table -> controls;  ai -> content
             every other sideways need is a port in src/core/ports.ts (ControlsSlot, DetailHost, BoxSlot, ...)
L3 primitives ui/* : 36 modules on Base UI, cva, cn, useFormat              basalt-ui/ui/<name>
L2 logic     router (TanStack Router)   data (TanStack Query, live, synced)
L1 core      .  provider, cn, VX, format, persisted, notify, createChannel, useNow, ports
L0 tokens    tokens.css  typography.css  prose.css  fonts.css  tailwind.css  theme-script

imports point down only; a violation is a build failure, never a waiver
src/charts and src/tokens stay Base-UI-free; src/charts/host.tsx is the only @tanstack/charts/react importer

profile      adds                                   declared in .basalt/manifest.json, per root
tokens       L0 CSS, tokens:css, stylelint          no React, no Tailwind
bridge       tailwind.css, cn, oxlint preset, skills
parts        L1-L4 except ./shell, basalt()         shell-less is the base case
app          ./shell                                ./shell plugs into ./page, never the reverse
```

Detail: [ARCHITECTURE 1-3](ARCHITECTURE.md). A prohibition is owned by the highest rung that can express it: absence, types, resolver, closed `@theme`, lint, build gate, ledger, dev assertion, gates. The edit-time hook and skill text never own one.
