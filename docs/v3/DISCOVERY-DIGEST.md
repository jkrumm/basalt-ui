## 0. Headlines

1. **The premise is half right.** Mantine limits bundle/provider and stock-agent alignment, not where recorded pain lives: 13 of argo's 234 friction rows are Mantine-structural (5.6%), about 94% carry over as requirements (consumer-argo). Bytes do not justify the move: 25 Base UI parts +112.2 KB gz vs 31 Mantine components +101.5 KB JS +36.2 KB CSS; the win is CSS (argo -40 to -55 KB) and control (gap-perf). Epos's first load grew 210.8 to 330.8 kB gz after shadcn/Base UI (epos).
2. **Logic survives, chrome does not.** 44% of source lines are Mantine-free (self-process-lessons); state ~80%, tokens 0 Mantine, charts near-free, shell ~60% law and algorithm. 126+24 test files (20.4k lines) port as-is, 136 render tests (37.8k) need a provider swap, 24+31 (31.2k) are real rewrites (gap-migration).
3. **Most consumers want less, not more.** Adopters use a fraction: finances/image/email: `./forms ./commands ./agent ./content` zero (small-apps); `./agent` 6,438 lines + 10,440 tests with 0 consumers (self-agent-content); 6 of 10 repos hand-roll tables (self-table-data). Product growth outran enforcement: 395 to 104 to 124 values, +25.4k src after 2.0, 29 minors in 25 days (self-process-lessons).
4. **Re-grown by every abandoner:** nav-as-data, query layer, settings sync, URL state, table, freshness. Epos: 44 stores, hand router, 163 requests with 25 effect guards, settings sync x2. Console: 3 UIs for one filter, ~600 lines hand SVG. Six independent freshness stacks, zero shared code (ext-realtime). This is the product's reason to exist.
5. **Distribution has been built and measured:** hybrid managed copy (logic, tokens, composites, lint, skills in npm; 40-60 visual primitives copied, tracked by a sha256 ledger and three-way merge) beat registry and compiled (gap-dist).
6. **Guardrails shrink by 90%:** ~7,700 authored lines to ~700-900 by buying @shadcn/lint and stylelint; the regex guard dies (gap-guardrail). But the reports propose about 30 more rules than its ceiling of 18 allows (section 4 row 4).
7. **The data table is unsolved upstream on the phone** (ext-table): no public reference does it; it must be designed from rules. Engine settled: TanStack Table v9 through `createTableHook`.
8. **AI runtime deleted:** plain `useChat` passes StrictMode, resume and errors; the only silent failure (Activity hide truncates) is fixed by a 10-line externally owned `Chat` (gap-perf). 6,438 lines go.
9. **Visual target is computed, not seen.** Warm ramp, three inks, four surface roles, flush inset; the Chrome proof covers token mechanics, not taste (gap-token, ext-visual). The owner's eye decides seven items (section 5).
10. **Release topology R1 is proven end to end in a sandbox** with three corrections; `semantic-release-monorepo` is a no-op in this repo, so AGENTS.md's "path-filtered" claim is false (gap-repo).
11. **Holes that no report closed:** owner Spec 523 was unreadable (auth), so its three questions are unknown; iOS Safari, VoiceOver and mobile `fetch` streams are unmeasured; a v3 scale change voids the codemod's 375/375 fidelity (gap-migration caveat, section 4 row 11).
