# Basalt UI v3: Phase 0

Date 2026-11-09. What the orchestrator does inline before the first `rd issue`. A lead reads the default branch only and cannot be raised per Issue, so the plan and the landing lane must be on master first. This page authorises no release and files nothing; `docs/v3/issues/index.json` is the Issue list.

## Steps, in order

Each step is a PR, rebase-merged; package and non-package changes stay separate commits; `make check` before merge. AGENTS.md-only changes use `docs:`.
