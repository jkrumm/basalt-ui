Date 2026-11-09. Binding: `ARCHITECTURE.md` (cited as "contract"). Slugs as in the digest. Tags: **F** read or run, **J** judgement, **U** unverified. Engine facts marked "1.5.0 tarball" were read from the published `@tanstack/charts@1.5.0` package on 2026-11-09 (d.ts and `docs/`); the repo still pins 1.1.0. ## 1. Decision summary

1. **The StatCard is the console anatomy on `Card`, `CardBand`, `Inset`, `IconTile`, flush inset, one shared left edge** (console 5.1, ext-visual 4.1). It is the first exemplar and gets the owner's verdict before fan-out (ext-factory).
2. **The card owns the box and the phase; the body is only called when there is something to draw.** `chart` is a `BoxSlot` that runs in `ready` and `stale` only, in a fixed clipping box. That removes argo rows 193, 206, 212, 219, 220 and invariant self-charts 28 by construction instead of by test.
3. **X labels move from the card into the chart kind; Sparkline has no tab stop unless it can answer.** Console hard-wires Sparkline's `PAD_X` in the card (`stat-card.tsx:146-148`); `./cards` may not import `./charts`. `axisLabels` on `Sparkline`/`MiniBars` resolves it, and the "now" slot doubles as the readout (self-charts 7.3). `axisLabels` present means interactive; absent means `tabIndex: -1`, `keyboard: false`, an image with a name. No tooltip extension: the engine floor (+31.1 KB) was measured without one (gap-perf).
4. **`ChartCard` is the same frame, in `./charts`, with `chart` as a box slot too.** The contract allows `children` only on `Page`, `Section`, `Card`, `Inset`. Argo's 75 sites split three ways (section 10); only the chart-body third is a codemod.
5. **Bump to 1.5 first, and the bump deletes code** (1.5.0 tarball, F on types, U on behaviour until spikes). `resolveChartTooltipPlacement` plus a `ChartTooltipPortalExtension` replaces the ~200-line MutationObserver clamp; `onRender` exposes `scene.chart` and `scene.scales`, replacing the DOM scrape; `scales/*` remove `d3-scale`; `keyedSelection`/`onSelect` give the click target finances and rollhook lack. **Wrong premise corrected:** self-charts row 12's floating-ui is not needed: the engine ships the collision resolver, and it would add a dependency to `./charts`.
6. **Series are a union discriminated by `mark`; `marks` only appends, and only through a counted escape.** Most C-bucket rows (consumer-argo 54, linewatch 7 of ~11 workarounds) are seams, listed in section 3; every 2.x series field is accounted for in section 4.
7. **`polarity` is required and `DeltaBadge` moves to `ui/badge`,** because both `./cards` and `./charts` render it and a sideways edge is a build failure (section 12).
8. **Own vs bound controls are the same prop, and both are widget handles.** A card binds to a global by declaring a widget that inherits it (`widgets: { latency: { range: globals.field.range } }`); a global handle in a card slot is a type error, so one global is never written from N cards. `ControlView` prints the override cue, so an author cannot forget it (gap-controls 6.2, 6.3).
9. **Verdicts have one legal home.** A verdict is `status` (dot + required word) or a zoned `ui/meter`, never a hue on a card, value or line. The 2.x `tone` rail and `tone` on values die; argo's verdict words move there (section 10).
10. **`KanbanCard` + one `onMove`, no Board, no engine; Timeline is a taught pattern.** The drag library attaches to a wrapper div in app code. `move` is required, so no card exists without the non-drag path (WCAG 2.5.7, gap-a11y). Timeline is a recipe on `DataPanel` (digest row 17, contract section 10).

**The 94%.** The owner's reason to leave Mantine (restyle control) stands and is served by owning every part here. It does not fix argo's C 54 and V 35 rows, which are our own API and anatomy; items 2, 3, 6, 9 and the seam table are aimed at those.

## 4. Public API sketch

Anatomy `data-slot`s: `card` (with `data-phase`), `card-band`, `card-info`, `icon-tile`, `inset`, `stat-figure`, `delta-badge`, `stat-sub`, `stat-chart`, `stat-footer`, `stat-meter`, `stat-row`, `kanban-card`, `chart-card`, `chart-box`, `chart-legend`, `chart-tooltip`, `sparkline`, `spark-labels`. Left edge var `--card-edge` (private): 16, 12 at `@narrow`, on every band and the inset.

```ts
// src/core/ports.ts (types only, no new value symbols; no composite .d.ts references ui/*, so MeterSpec lives here)
type Phase = 'ready' | 'loading' | 'stale' | { tag: 'error'; kind?: 'forbidden' | 'not-found'; retry?: () => void; message?: string }  // 'empty' is derived from `empty`: it cannot lack a cause; a `QueryStateLike` error with a structural `status` of 403 or 404 sets `kind`; `forbidden` shows no Retry
type QueryStateLike = { isPending: boolean; isError: boolean; isRefetchError?: boolean; isPlaceholderData?: boolean; error: unknown; refetch?: () => unknown }
type CardAction = { label: string } & ({ href: string } | { onSelect: () => void })
type Empty = { cause: string; action?: CardAction; filtered?: { reset: () => void } }  // no-results under active filters: renders Clear filters; DataTable derives it from `request`, frames feed it from useReset()
type FrameState = { phase?: Phase | QueryStateLike; empty?: Empty | null }     // empty wins once the query settled; data-phase prints the result
type Box = { height: number | 'fill'; phase: 'ready' | 'stale' }
type BoxSlot = (box: Box) => ReactNode
type Delta = { value: number | string; polarity: 'up-good' | 'up-bad' | 'neutral'; label?: string }
type Status = { tone: Tone; label: string }                               // the verdict home: dot + word
type Fact = { label: string; value: string | number }
type FootFacts = readonly [Fact | null, (Fact | null)?]                   // capped at 2; null drops one, so argo's 0-2 conditional rows type-check
type MeterSpec = { label: string; value: number | null; min?: number; max: number; zones?: readonly [MeterZone, MeterZone, ...MeterZone[]]; format?: (v: number) => string }
type MeterZone = { to: number; tone: Tone; label: string }
type FrameHead = { title: string; subtitle?: string; icon?: IconComponent; info?: string }

// src/cards/contract.ts
type CardTarget = { href: string; onSelect?: never } | { onSelect: () => void; href?: never } | { href?: never; onSelect?: never }
type StatCardProps = CardTarget & FrameHead & FrameState & {
  value: number | string | null; unit?: string                   // null renders a muted dash: absent, never zero
  delta?: Delta; status?: Status; sub?: string
  chart?: BoxSlot                                                // box.height 72: plot 56 + label row 16
  footer?: FootFacts; controls?: ControlsSlot
  menu?: readonly [MenuAction, MenuAction, ...MenuAction[]]      // popup lazy-loads ui/menu on first intent
}
type StatRow = { label: string; value: string | number; delta?: Delta; bar?: { value: number; max: number } }
type StatCellProps = CardTarget & FrameState & { label: string; qualifier?: string; info?: string; value?: number | string | null; unit?: string
  delta?: Delta; status?: Status; sub?: string; srText?: string; meter?: MeterSpec; chart?: BoxSlot /* box.height 28 */; rows?: readonly StatRow[] }

type DataPanelProps = FrameHead & FrameState & { controls?: ControlsSlot; toolbar?: ControlsSlot; menu?: BoxSlot; legend?: readonly LegendEntry[]
  skeleton: { rows: number } | { height: number }                // required: rows 193, 206
  body: BoxSlot }

type ColumnRef<C extends string> = { id: C; label: string; count: number; disabled?: boolean }
type Move<C extends string> = { id: string; from: C; to: C; index: number }
type KanbanCardProps<C extends string> = {
  id: string; title: string; href?: string; age?: string; meta?: readonly [string] | readonly [string, string]
  chips?: readonly [CardChip?, CardChip?, CardChip?, CardChip?]; reason?: { icon?: IconComponent; text: string }; status?: Status; menu?: readonly MenuAction[]
  move: 'static' | { column: ColumnRef<C>; index: number; columns: readonly ColumnRef<C>[]; onMove: (m: Move<C>) => void; dragging?: boolean }
}

// src/charts/contract.ts
type SeriesBase<D> = { key: string; label: string; color: SeriesColor; failed?: boolean /* partial data: legend reads unavailable, nothing is drawn, phase stays ready */; axis?: 'left' | 'right'; note?: string; role?: 'series' | 'overlay' | 'reference'
  legend?: false; tooltip?: false; format?: (v: number, d: D) => string; getMarker?: (d: D) => Marker | null }
type Y<D> = { y: (d: D) => number | null }
type Series<D> = SeriesBase<D> & Y<D> & ({ mark: 'line'; curve?: CurveName; dash?: boolean; area?: 'fade'; weight?: 'quiet' | 'strong'; gaps?: 'connect'; parent?: string }
  | { mark: 'bar'; stack?: string; opacity?: (d: D) => number } | { mark: 'dot'; r?: (d: D) => number })
type LegendEntry = { key: string; label: string; color: SeriesColor; swatch?: 'solid' | 'dashed'; failed?: boolean }   // no fake series for legends

type CartesianChartProps<D> = { data: readonly D[]; x: XConfig<D>; y?: YConfig; series: readonly Series<D>[]; ariaLabel: string; summary?: string; table?: boolean
  height?: number | 'fill'; phase?: Phase | QueryStateLike; tooltip?: ChartTooltipConfig<D> | false; zones?: ...; refLines?: ...; cursor?: string; selection?: ChartSelection<D>; marks?: CustomMarks<D> }
// CartesianChart.custom((plot) => marks[]) is the only way to build CustomMarks; lint --stats counts it.
// y: { domain?: [number, number] | { floor?: number; ceil?: number; pad?: number } | ((v: Extent) => Extent); gutter?: number }

type SparkPoint = number | null | { at: Date | number; value: number | null }
type SparklineProps = { series: readonly SparkPoint[]; ariaLabel: string; height: number | 'fill'; width?: number; form?: 'line' | 'area'
  reference?: number | 'mean'; axisLabels?: readonly [string, string, string]; format?: (v: number) => string; summary?: string }
type MiniBarsProps = Omit<SparklineProps, 'form' | 'reference'> & { highlight?: number | 'last' }

type ChartFigure = { value: number | string | null; unit?: string; delta?: Delta; period?: string; status?: Status }
type ChartCardProps = FrameState & { figure?: ChartFigure; footer?: FootFacts; controls?: ControlsSlot; menu?: BoxSlot; height?: 'auto' | 'short' | 'fill' }
  & ((FrameHead & { chart: BoxSlot }) | (Partial<FrameHead> & { phase: 'loading'; chart?: undefined }))   // second arm: a Suspense fallback
```
