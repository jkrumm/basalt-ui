# Concept: controls and URL state (`./router` controls half, `./controls`)

Date 2026-11-09. Contract: `ARCHITECTURE.md` (A§n). Evidence slugs as in the digest. Tags: **F** run or read (cited), **J** judgement, **U** unverified. `DPO 14.x` = DEFAULT-PENDING-OWNER, sub-items of A§12 row 14, each with its one-line alternative (section 10). Shell, page kit and table are other concepts; this one owns the state model, the binding and the control renderers. Forms: `FormField`/`FormRow` here; drafts, guard, submit and storage keys are owned by `state-persistence-forms`. Revised 2026-11-09 against adversarial findings (Review Log at the end).

## 1. Decision summary

1. **Two axes, never mixed.** _Scope_ is where state lives: `global`, `page`, `widget`, `sub-item` (all URL), plus the non-router lanes `device`, `synced`, `draft`, `memory` and one app-owned lane, the session mirror (1.2). _Home_ is where a control renders (A§6, closed list). A control has one scope and one home. F: the router half passes 37 tests plus `tsc` on Router 1.170.46, re-run today (gap-controls, `/tmp/scope-proto`), but only for the `enum`, `string`, `multi` kinds on code-based routes: `number`, `boolean`, `range` and file routes are untested (S1, S8 before freeze).
2. **The URL is the carrier for everything a link should reproduce.** Globals = root `validateSearch` + `[stripSearchParams, retainSearchParams]` (order fixed inside the library); pages own their keys; widgets own `w.<id>.<field>` keys on the page route. Codecs accept any router parse config (1.3). No nuqs, no `createGlobalStore`, no store object or context (ext-state, ext-tanstack).
3. **The widget-state contradiction is settled in 1.1: widget overrides are URL keys; a widget can never write a global.** Saved views are named pointers at URL state, owned by `DataTable` in 3.0; page-level saved views are a recipe, not an export.
4. **Precedence is one law:** `w.<id>.<field>` override, else the inherited handle's URL value, else the static fallback; per key, tile wins (scalars replace), invalid values drop to the next layer. A remembered per-user value is not a layer (4.5).
5. **A control is data, not children.** `FilterSpec<T>` (handle + label + facets) rendered by the HOME: pill, row or inline. The census (`Filters (n)`, `Reset all`) derives from handles, so the registry, the double mount and the `null`-registry trick are deleted (self-controls-forms rows 6, 7, 13).
6. **Filter kinds are not exports.** `FilterSet`, `filterSlot`, `spec`, `ViewTabs`, `ControlHome`, `FormField`, `FormRow`, `FormFooter`, `toSubmitErrors`, `useFormDraft` are the ten `./controls` symbols (A§3); the renderer is picked by `handle.kind`. Exactly the 10 + 5 allocated (`./router`: `defineControls`, `field`, `navTarget`, `defineNav`, `routerDefaults`); everything else is a method on the returned object, the escape included (`filterSlot.custom`, not a tenth symbol).
7. **A widget override shows itself and offers reset, produced by one renderer** so a page author cannot omit the cue (F, `ControlView` in the prototype). Never colour alone.
8. **Sub-item navigation is a page primitive on a `push` field**, not a shell region (`InnerNav` in `./page`; binding contract here). Back walks sections; items are real links (F).
9. **Forms are the draft lane, never URL.** `FormField`/`useFormDraft` take a structural `FieldLike`; TanStack Form 1.33.5 stays the consumer's dependency. `@mantine/form`, `inputProps`, `fieldKey`, `forms-field-key` die. Semantics of draft, guard, submit: `state-persistence-forms` (one owner).
10. **Premises challenged.** ext-dense's "types stop widgets writing the URL" is replaced by "types stop widgets writing a _global_". The digest's `createGlobalStore` idea is rejected on measured evidence. The 2.x URL-field `persist` (mirror as a resolution layer) is removed, as A§12 row 14 and `state-persistence-forms` say: it makes shared links non-reproducible and a back entry re-apply today's preference (F, gap-controls 5.4). Argo's remembered windows become a recipe (4.5).
11. **Mantine was 5.6% of the friction, but this domain is the one most worth freezing:** argo calls the typed field stores "the single best-loved piece", rb's 10-field page is ~40 lines (consumer-argo, consumer-rb). The vocabulary (`field.*`, `FieldHandle`, `{v,value}` envelope, URL codec) is frozen (A§4.4); the factories rename by codemod (digest row 13).
12. **Nothing here needs a library beyond Router.** Base UI 1.9.0 supplies Popover, Select/Combobox `multiple`, NumberField (`onValueCommitted`), ToggleGroup, Tabs, Drawer (as `Sheet`), Field (all in A§3 `ui/*`); `react-day-picker` 10.0.2 only behind a lazy edge (Contract Exceptions).

### 1.1 The widget-state contradiction

| Claim                                                                                           | Source                                                          | Verdict                                                                                                                                                                      |
| ----------------------------------------------------------------------------------------------- | --------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Widget = local state; types make `scope:'widget'` unable to write the URL                       | ext-dense 3.5 (J, U on primaries)                               | Refined: a widget handle can write only its own `w.` key, never a global or page key                                                                                         |
| Widget override is a stable per-widget URL key; a shared link must reproduce an overridden card | gap-controls (F, 37 tests), owner brief ("bound to the router") | Adopted                                                                                                                                                                      |
| "App" scope = user setting, persisted or synced                                                 | ext-dense 3.5                                                   | Same thing as the `device`/`synced` lanes: not a control scope, no URL                                                                                                       |
| Saved view instead of a widget URL key                                                          | A§12 row 14 alternative                                         | Not now: no consumer names a page-level saved view (grep over 41 reports: table views only); a saved view needs storage, naming, ownership and, if shared, a server contract |

The test that separates the two lanes, taught in `basalt-state`: _would a recipient of the link need this to see what I see?_ Yes: URL (global, page, widget). No, but it survives my next visit: device lane (`url:false`). No, and it must not survive: memory or component state (hover, open, pending text, legend toggle). Per-card toggles such as linewatch's `compact` stay device (`url:false`, F consumer-linewatch). URL length is bounded structurally: at most 2 scalar fields per widget by type (J, matches "card controls <=2"); F (inline calc): 10 widgets x 2 overrides plus globals = 687 chars, 20 widgets = 1,307. No length assertion until a real limit is measured (gap-controls lists it unmeasured; the structural bound already caps it).

### 1.2 Store-primary sessions: shutterflow Photos (evidence: consumer-shutterflow 49, 60, 97)

Photos is a reducer store (`photos-state.ts`, 345 lines) mirrored to 12 params (`scope collection focus density stage rating label camera kw rejected from to`) by a 250 ms trailing, replace-only write, because a held arrow key moves `focus` ~30x/s; `hydrate.ts` suppresses the router echo of its own writes (`noteRouteWrite`). A URL-primary handle cannot serve this: `use()` would read the URL, so the focus ring would lag 250 ms. A per-field `debounce` option is therefore rejected. **Decision (J, DPO 14.7): store-primary lane, app-owned.** The store stays the truth; its chips and tabs bind as `externalField` handles (memory lane, `url:false`), so `FilterSet`, census and cue still render them; the URL mirror (own plain `validateSearch`, debounced `replace`, echo suppression, ~150 lines that exist) stays in shutterflow, greppable as the counted "app-owned URL mirror". One copy is below the 3-copy cut test (A§10): recipe in `basalt-state`, no export. `router-search` does not flag a plain validator that no `defineControls` owns. `use-committed-field`'s 200 ms debounce is for text inputs only. Alternative: ship `mirror(store, {debounce, echo})` once a second consumer names it.

### 1.3 URL value format is router-parse-agnostic (consumer-shutterflow 60; `router.tsx` sets `parseSearchWith((v) => v)`, `stringifySearchWith(String)`)

Shutterflow's string-only router writes `?rating=1,2&kw=a,b&density=128`; argo's default JSON router writes arrays as `["a","b"]` and parses `?item=123` to a number. Codecs therefore **decode from any raw form and never touch the router codec**: `multi` accepts an array or a comma string; `number` a number or a numeric string (`NUMERIC_RE`); `boolean` `true`, `'true'`, `'1'`; `string` any scalar via `String()`. Writes emit native values and the app's `stringifySearch` renders them. `defineControls` and `routerDefaults` never set `parseSearch`. Frozen identity is the pair (param name, decoded value set): golden fixtures run the codec matrix against both router configs, with shutterflow's Photos and Settings URLs as fixtures (issue 1).

## 3. Scope model

| Scope          | Declared on                                                                              | Lives in                        | History                   | Retained across routes                                                                                                | Resolution                                                   |
| -------------- | ---------------------------------------------------------------------------------------- | ------------------------------- | ------------------------- | --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| global         | root route `defineControls({scope:'global'})`                                            | URL                             | replace (DPO 14.1)        | yes                                                                                                                   | URL > fallback                                               |
| page           | page route or a layout route shared by children, `scope:'page'`, optional `retain: keys` | URL                             | replace                   | no; only `retain` keys, only inside the subtree of the route that mounts the store's middlewares (argo `finance.tsx`) | URL > fallback                                               |
| widget         | `widgets:` on a page store                                                               | URL `w.<id>.<field>`            | replace                   | no                                                                                                                    | override > inherited > fallback                              |
| sub-item       | page route, field `history:'push'`                                                       | URL                             | push                      | no                                                                                                                    | URL > fallback                                               |
| device         | `url:false` field, or `persisted(key)`                                                   | `basalt:<id>` `{v,value}`       | n/a                       | n/a                                                                                                                   | value > fallback; server HTML = fallback                     |
| synced, draft  | `createSyncedState`, `useFormDraft` (`./data`, `./controls`)                             | mirror + server, or `persisted` | n/a                       | n/a                                                                                                                   | other concepts                                               |
| memory         | `url:false, persist:false`, or `externalField`                                           | module or component             | n/a                       | n/a                                                                                                                   | session                                                      |
| session mirror | app-owned: `externalField` handles over a store, app writes the URL (1.2)                | store, mirrored to URL          | app (debounced `replace`) | n/a                                                                                                                   | store > URL on mount; app hydrates from non-echo navigations |

Rules (F unless marked): defaults are absent from the URL while the validated search stays complete; an override equal to the global still pins (key presence is intent); exits are `clear()` and `Reset overrides`; deep link with override and global both set honours the override, names the global in the cue, rewrites nothing; widget ids are literal and app-unique; `w.` is a reserved prefix; two stores owning one param throw at definition; `clear()` and every write use explicit `undefined`, never `delete` (a retained key is not cleared by `delete`, F gap-controls 5.2). Widget fields are single-param **scalar** kinds in 3.0 (`enum`, `string`, `number`, `boolean`); the tile value replaces the inherited one. `multi` and `range` as widget fields are type errors until a consumer names an inherit-then-override card (none does: argo's per-chart selects are `{url:false}` device fields; DPO 14.5). A future `merge` must define the disjoint case (global `[eu]`, tile `[ap]`: intersection is empty and "empty = all" would show everything, the opposite of narrowing) as an explicit empty selection with the cue, never as all. `retain` on a page store reuses the global retain machinery with `[strip, retain(keys)]` mounted on the layout route (J, S8); a page key never becomes app-global, so `/garmin-health` does not show finance's range. A widget handle's `isDefault` means "no override", not "equals global".

## 5. Public API sketch

```ts
// src/core/ports.ts (L1): the only thing ./controls sees of the router half
export type ControlHandle<T> = {
  key: string; kind: 'enum'|'multi'|'string'|'number'|'boolean'|'range'; options?: readonly { value: T; label: string }[]
  use(): [T, (v: T) => void]                       // FROZEN 2.x shape (digest row 13); the prototype returns `ControlState<T>` (with `reset`): reconcile in issue 2
  useSource(): { source: 'own'|'inherited'|'override'; inherited: T | undefined }
  clear(): void; isDefault: boolean }              // clear() UNSETS, never writes the fallback

// ./router
const globals = defineControls({ id: 'globals', scope: 'global', fields: {
```
