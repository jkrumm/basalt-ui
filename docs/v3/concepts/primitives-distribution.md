# Primitive layer and distribution

Date 2026-11-09. Domain concept under `ARCHITECTURE.md` (the "contract"). Tags: **F** run or read (cited), **J** judgement, **U** unverified. **DPO** = DEFAULT-PENDING-OWNER, numbered as contract section 12. "Today's run" marks spikes made for this document in throwaway directories.

## 1. Decision summary

1. **Basalt authors 35 primitive modules on Base UI 1.9.0 and ships them in npm as `basalt-ui/ui/<name>`.** This is where the owner's reason for leaving Mantine lands: every class string, variant, slot and default in `src/ui` is ours, with no Styles API or theme object in the way.
2. **A consumer takes ownership of a primitive only through `eject`, per file.** The import specifier never changes, so npm composites follow the local file (F, gap-dist 3.1).
3. **The assignment says "managed copy"; contract 4.1 overrides it.** Managed copy of all primitives survives as `eject --all`, one command per app, and F3 can make it the `init` default. DPO 4; alternative: `eject --all` at init. **No public `@basalt` registry at 3.0** (DPO 4; alternative: generate `registry:base` items from `src/ui`, additive later).
4. **The ledger tracks only what can diverge:** ejected primitives (seed digest, merge base) and the agent files `sync` already manages. An un-ejected primitive cannot drift, so it has no ledger row.
5. **`sync` three-way-merges upstream into ejected files.** Today's run found two defects in the merge as gap-dist built it: a consumer formatter turns every upstream change into a conflict, and the eject header conflicts with any edit to line 1. Section 6 fixes both. Adopted shadcn files are not merged at all: they share no ancestry with a seed.
6. **Every Mantine symbol the fleet imports has an answer, except `WeekView` and `MonthView`** (section 9, DPO 10). Census today: 113 symbols, 1,991 imports, 425 non-test files. Eight need new exports, all inside the 36 modules.
7. **Base UI behaviour is half a primitive.** It never draws focus, hardcodes two English strings, drops `createHandle` calls with no mounted root and has no date picker (ext-base-ui, gap-a11y). Section 4 names the owned half per module.
8. **Our own API has to improve too.** Closed variants, contract and docs generated from one cva table, unknown flags that exit 1 and frozen-install fixtures answer the tooling, docs and anatomy rows in argo's ledger, which no library change touches. This layer adds 0 lint ids, 0 CLI verbs, 0 modules: the contract's 18, 8 and 35 stand; `--app` and `--raise` are flags.

// .basalt/manifest.json at the repo root. `files` and basaltVersion exist today (src/cli/index.ts:1075); the rest is new
interface Manifest {
  version: 2
  profile: 'tokens' | 'bridge' | 'parts' | 'app'
  basaltVersion: string
  roots?: Record<string, Profile>
  deepRender?: string[]
  authoredContent?: string[]
  viewports?: string[] // guardrails E6, ai-mdx 3, skills 3.7
  managed: Record<string, string> // raw-byte sha256 of each rendered agent file (guardrails E1)
  ejected: Record<
    `${root}#${name}`,
    {
      path: string
      fromVersion: string
      seedDigest: string | null
      reason: string
      origin: 'seed' | 'adopted' | 'local'
    }
  >
}
// .basalt/budget.json. `eject` writes it only through --raise; `migrate` sets adopted and profileFloor once
interface Budget {
  ejects: number
  adopted: number
  waivers: number
  escapes: number
  profileFloor: Profile
  raises: { field: string; from: unknown; to: unknown; consumer: string }[]
}
// src/ui/button.guard.ts. A `closed` half (@ts-expect-error) stays in the repo and is dropped at eject
type Called = {
  variant?: 'primary' | 'secondary' | 'ghost'
  size?: 'md' | 'icon'
  loading?: boolean
}
export const requires = (c: Called): ButtonProps => c // removing a called variant fails tsc; adding one passes

## 6. Ledger, sync, doctor

| Tracked class        | Paths                                               | Record                                                         | `sync` does                                                                                                                 | Drift means                                     |
| -------------------- | --------------------------------------------------- | -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| Un-ejected primitive | `node_modules`                                      | None                                                           | Nothing                                                                                                                     | Impossible                                      |
| Ejected primitive    | `<root>/components/ui/<name>.tsx`                   | `manifest.ejected`, `.basalt/base/<root-dashed>/<name>.tsx`    | Three-way merge (F8 PASS: merge support not raised; the sync matrix is sized to Base UI minors, `spikes/upstream-churn.md`) | Expected                                        |
| Adopted shadcn file  | Same                                                | `origin: 'adopted'`, base = seed                               | No merge: advances base and digest, prints the seed diff                                                                    | Expected                                        |
| Guard                | `<root>/components/ui/<name>.guard.ts`              | Covered by `seedDigest`                                        | Overwrites                                                                                                                  | `doctor` error: `requires` is basalt's contract |
| Agent files          | `.claude/{rules,skills}/basalt-*`, AGENTS block     | `managed` raw-byte digest of the rendered file (guardrails E1) | Render, compare, write; an edited file is left and reported                                                                 | Reported; `--force` finishes                    |
| Generated presets    | `.oxlintrc.basalt.json`, `.stylelintrc.basalt.json` | None                                                           | Rewrites; `eject` regenerates too                                                                                           | `sync --check` red                              |
| Tailwind sources     | `<app>/.basalt/sources.css`                         | Gitignored                                                     | `basalt()` regenerates each run                                                                                             | Impossible                                      |

**Roots.** Paths key off `manifest.roots`, which replaces 2.x `basalt.roots` (default `src`; F: argo lists `apps/dashboard/src`, shutterflow `apps/desktop/src`). Manifest, bases and budget sit at the repo root beside the `basalt-ui` dependency; the ceiling is per root. `eject` without `--app` exits 1 listing the roots when there are 2+. `basalt()` walks up to the manifest, picks the root under its Vite `root`, aliases only that root's ejects. `sources.css` is per app, so `@import '../.basalt/sources.css'` stays textually the same and two Vite apps cannot overwrite each other; `paths` lands in that app's `tsconfig.app.json`. `migrate` adds missing roots (shutterflow's `gallery` imports basalt in 5 files and is unlisted). During sibling-app cutover only the v3 root is listed, so 2.x apps stay unmanaged.

`normalizeForLedger` is gone: formatter ignores keep managed files byte-stable, and one `oxfmt` run marks a copied TSX as drifted (F, gap-dist 3.1), which is why ejected TSX is merged, never hashed. `seedDigest` is sha256 of the shipped seed plus its guard, read from the tarball, never from the consumer's file. The guard counts because a composite can start calling an existing variant without the seed changing.

**`sync` on an ejected file:**

1. Skip `origin: 'local'` and print it. Skip when `seedDigest` matches. `origin: 'adopted'`: rewrite base, advance `fromVersion` and `seedDigest`, overwrite the guard, print the `git diff` command that shows what the seed changed, stop. A base-nova file shares no ancestry with a seed, so a merge could only conflict or mis-merge (J; no adopt run in gap-dist). A11y and CVE fixes reach it by hand.
2. Strip the header line (F, today's run: left on line 1 it conflicts with an upstream edit to line 1, exit 1). Format local, base and shipped with the project's formatter into temp files (CE3); none resolved, merge raw and say so.
3. `git merge-file --diff3 -L local -L base@<from> -L shipped@<to>`.
4. Write header plus result. Advance base, `fromVersion`, `seedDigest` **even on conflict**, because a re-run over markers would stack them. Overwrite the guard. Exit 1 if any file conflicted; a second run changes nothing.

`--check` runs steps 1-3 in temp and writes nothing; exit 0 clean, 1 on anything to do. Seeds import siblings and `cn` by real specifier, so eject rewrites no import. The base stays the raw seed, so a later formatter config change cannot stale it.

| `doctor`, profile `parts` and up unless noted                                                                              | Result                                                                                       |
| -------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| Profile declared, `basaltVersion` reconciled, peers of imported subpaths present                                           | Error names the `bun add`                                                                    |
| Declared profile below an imported subpath (`ui/*`, L4: `parts`; `./shell`: `app`) or below `profileFloor` (every profile) | Error names the import                                                                       |
| `budget.json` looser than its merge-base copy with no matching `raises` row (every profile)                                | Error; no git history: reported as skipped, never passed                                     |

| Conflict markers in an ejected file; a `SLOTS` entry for the module missing from it                                        | Error with path or slot                                                                      |
| `ejects` or `adopted` above `.basalt/budget.json`                                                                          | Printed during `next`, error from 3.0.0 (`lint` exits 1 on the same read, so CI enforces it) |
| `<root>/components/ui/*.tsx` absent from the manifest                                                                      | Error: adopt or delete                                                                       |
| `.basalt/` missing from the formatter ignore; zero files seen by a check                                                   | Error; reported, never passed                                                                |

**`basalt()` at `buildStart`** fails on a missing peer or a stale digest, in deploy builds where CI does not run, and needs no git. With ejects it adds the alias, `ssr.noExternal`, `optimizeDeps.exclude` and `@source not` for each ejected module's npm copy; with none it adds nothing. `eject` exits 1 without `basalt()` in that app, because the alias has no host (the fleet is all Vite; U elsewhere). **The limit of the gate:** an agent with a shell can still run `--raise`. The guarantee is that the raise cannot be silent: its own diff, a named consumer, a `lint --stats` count, at rung 7. The PreToolUse hook on `.basalt/**` does not intercept the CLI and owns nothing here.

## 7. What eject means

| Question                 | Answer                                                                                                                                                                                                                                                   |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Transfers                | Structure: markup, variants, parts, behaviour wiring. Never tokens: `no-raw-colors`, `no-arbitrary-values` and class rules stay on inside; `no-restyle` is off in the file, on at call sites                                                             |
| Scope                    | One primitive. Composites never eject; rung 4 or 6 replaces one                                                                                                                                                                                          |
| Still binding, invisible | `requires`, frozen `data-slot` names, the digest gate bind. Invisible to the guard: deleting the focus ring or hit overlay. `sync` still delivers fixes, but a deliberate deletion is the app's call                                                     |
| Fixes                    | A11y and CVE fixes merge into `origin: 'seed'`; a dependency CVE is a `package.json` bump as before; `adopted` and `local` port by hand                                                                                                                  |
| New variant              | Allowed locally, since a guard is a superset check. Three ejects of one variant fleet-wide go upstream (`lint --stats`, `fleet.json`)                                                                                                                    |
| Reversal, on-ramp        | `--undo` per file. Whole app: `eject --all`, back by delete and `sync`. No codemod either way. `--adopt` only files with real edits; delete pristine base-nova files for the npm module. The guard forces adopted files to accept basalt's variant names |

The contract's accepted cost stays open: linewatch and argo asked for greppable owned source, and the npm default puts it in `node_modules`. The owner calls owning and restyling the point of the move, so this is the DPO most likely to be overturned. Flipping it costs one command per app, and F3 tests it.

## 8. Public registry: no

The format's update path is its weak point: no `version` field, no lockfile, and `add --overwrite` destroyed 4/4 edits while stale stayed indistinguishable from edited (F, gap-dist 3.7). A re-add appended a duplicate CSS import (F, gap-dist 3.4). A registry item has no guard, manifest row or ceiling, and no consumer needs one: console and epos enter through `--adopt`. Re-entry is cheap, because `src/ui` is plain files and `registry:base` with `extends: none` works (F, gap-dist 3.4), so it waits for a named consumer. Agents read `docs/<name>.md`, `llms.txt` and the seed source. No MCP at 3.0 (DPO 18).
