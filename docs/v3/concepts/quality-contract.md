Evidence: `gap-a11y-i18n-print-contract` (`gap-a11y`), `gap-performance-budgets-and-library-tiebreaks` (`gap-perf`), `gap-migration-coexistence-and-consumer-testing` (`gap-migration`), `ext-toolchain`, `ext-tanstack-ecosystem`, `ext-base-ui-primitives`, `self-process-lessons`, `consumer-weatherorb`. ## 1. Decision summary

1. **Quality is one parametrised matrix, not twelve test files.** The eight playground routes x {1800x1200, 390x844} x {light, dark} run eight assertions (axe, document overflow, focus ring, focus-not-obscured, forced colours, text spacing, fit on worst-case data, reduced motion); the carried effective-hit-box tests (`hit-floor`, `hit-overlap`) run over the same routes; the pseudo-locale is one 390 dark cell per route, not an axis; plus an overlay-open axe pass and one print cell per route (section 4). Sampled in `make check`, full in `make evidence`. **The exemplar proves the composites, not a consumer's compositions**: consumers run the same assertions on their own route list through `quality.*` (sections 7, 9). Of argo's anatomy rows (bucket V 35; ledger V 180-220 are 40 micro-defects in 4 components) only the fit/overflow subset is assertable, and only on worst-case data; the rest is construction (equal phase heights, built-in anatomy), owned by the cards and charts concepts' layout tests (consumer-argo 196, 230).
2. **Premise challenged: "axe in the suite" is not new work to schedule, it is the missing floor.** Today basalt has zero axe; the first pass (64 runs, ~2 min) found 7 rule classes, 2 critical, all in code a type or a shell rule owns (F, gap-a11y 1.6). So each finding gets a rung above the test: types for names (R3, R4), shell structure (R1), one catalog string feeding both label and visible text (R2), tokens (R5). Axe stays the gate behind them, not the first line.
3. **WCAG 2.2 AA, no AAA claim, no APCA** (not in 2.2 or EN 301 549 V4.1.1, F gap-a11y 1.1). The 2.2 additions map to existing machinery: 2.5.8 = `--vx-hit` 24, 2.4.11 = a new focus-not-obscured sweep, 2.5.7 = the "Move to" menu (charts-cards-kanban), 1.4.12 = a new text-spacing injection test.
4. **i18n is a typed message catalog plus `locale`/`timeZone` on the provider; no translation system, no RTL, English only.** The render-phase `defineFormat` global dies. **Catalog defaults live with their area in `src/core/messages/<area>.ts`, never in the provider**: otherwise ~100 strings land in the 5 KB provider (J, ~1.2 KB gz) and weatherorb's `/map` arithmetic breaks. Leaves work with no provider (English, UTC), A§1. Formatting outside React (argo, shutterflow `*-model.ts`) uses `createFormat`; `date`/`dateTime` take a per-call `timeZone`; SPAs and desktop apps pass `timeZone="host"` (section 7).
5. **Provider JS <= 5.0 KB (A§0, A§1) is a cap, not a derived number.** weatherorb `/map` sums to ~696 KiB against 704 only if the provider is 5 KB; the sum carries +/-15 KiB (U, gap-perf 3), larger than the 8 KiB headroom. So `PROVIDER_ONLY` is set by the section 6 method after Q1 (measured +5%, never above the 5.0 cap; a measurement above it files a Contract amendment, no silent raise), and weatherorb's real build is the only proof of its 704 KiB bar (G4).
6. **React Compiler: the library ships uncompiled and compiler-clean.** Measured: on the 200-row virtual window the compiler changes sort by +0.6 ms and nav-to-paint by +3 ms (noise); its -31% sort and -78% parent re-render appear only with 10k rows in the DOM, the case the table concept's dev assertion (>500 client rows without `virtual`) forbids, so the runtime gate times only the virtual 10k and the 500-row non-virtual cases (F, gap-perf 4.1; section 6). Consumers opt in with `@rolldown/plugin-babel` + `babel-plugin-react-compiler` 1.0.0; fixtures run compiler off and on (react.dev: test both).
7. **Print is the screen page with chrome off.** Shell concept owns the unclip, tokens own the light scheme (`@media not print` dark block); this concept owns the print cells and the PDF page-count test (today 24 of 80 rows print, F). Reports, invoices, paper type stay the consumer's.
8. **SSR is allowed by construction; three proofs run now** (`tokens`, `.`, fixture `full`) with `renderToString` + `hydrateRoot` + a positive control (section 5). The other subpath rows are contracts proved when their first SSR consumer files the Issue: the only SSR consumer is weatherorb's zero-JS `/`, argo, rb, linewatch are SPAs. Dashboards are SPA; public pages `ssr: true`; maps `ssr: false` (ext-tanstack 5).
9. **Consumer testing kit = `./testing` + `data-slot` + two recipes.** `renderApp`, `settled`, `installDomShims`, `SLOTS`, `expectShellInvariants` ship, plus one new tooling symbol `quality` (Page-taking browser assertions the matrix needs anyway: axe with settle, ring walk, focus-not-obscured, text spacing, overflow, `setScheme`). Per-route byte bars and the compiler-active check are recipes. `basalt-ui budget` stays refused: 2 hand-rolled copies (weatherorb `bundle-report.ts`, argo `scripts/evidence/bundle.ts`), a 30-line recipe does it. `./test/a11y` is **reversed** into `quality` (Contract Exception 1, DPO 18.6): shutterflow has two diverged axe copies (`desktop/a11y/axe.ts`, `gallery/tests/a11y.spec.ts` duplicate `WCAG_TAGS` and `BLOCKING`), argo has none, the matrix is the third, and exporting costs no new code.
10. **Visual regression has two layers:** geometry and computed-style asserts (the oracle) and `one-look` (sameness across profiles). Pixel baselines are cut from the repo until a defect class escapes both (additive); `make evidence` still captures `shot` images for the owner's eye, undiffed. Consumers may keep their own baselines (shutterflow ADR 0028 is an owner directive: 26 PNG + geometry invariants; `expectShellInvariants` covers its nav-pitch and footer-inset checks); basalt neither ships nor forbids them. "Regenerate once per migration" rests on a check: the `one-look` computed-style snapshot is diffed per release and a diff with no named `valueShifts` row fails the release PR (J; migration concept owns the row shape).
11. **iOS Safari and VoiceOver are spikes with pass criteria, not gates.** Playwright's iPhone descriptors run its own WebKit build with a fixed viewport; no VoiceOver, no dynamic toolbar, no keyboard (F, research 01a1c0e6). They catch engine bugs on Linux; Q6 adds a desktop WebKit descriptor for macOS-webview consumers (shutterflow is Tauri WKWebView; engine family only, image-decode differences stay unproven); the six device checks (section 10, M1-M6) need an iPhone and a Mac.
12. **The owner's "colour earns its place" reaches here only through contrast:** status never by colour alone, no opacity dimming of text (use `faint`; owned as one pattern on `tw-off-law`, rung 5, section 11), focus ring solid (tokens-visual d21).

// . (no new value symbol; types are free)
export type CalendarDate = `${number}-${number}-${number}` // zone-less; never display new Date('YYYY-MM-DD')
export interface Format {
  // names follow 2.x `format/`, not re-read here (J)
  number(n: number, o?: Intl.NumberFormatOptions): string // non-finite -> '—'
  percent(fraction: number, o?: Intl.NumberFormatOptions): string // decimal comma under de-DE
  money(n: number, currency: string, o?: Intl.NumberFormatOptions): string // no default currency
  date(
    v: Date | number | CalendarDate,
    style?: 'short' | 'long' | 'month' | 'weekday',
    o?: Intl.DateTimeFormatOptions,
  ): string // CalendarDate prints in UTC, Date in o.timeZone, else the provider zone

}
