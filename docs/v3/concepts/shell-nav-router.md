## 1. Decision summary

Owning this markup is the reason for the move: obsidian's 14 `!important` and `header.mantine-AppShell-header`, shutterflow's `.mantine-AppShell-header` DOM query, basalt's own margin-restating, `:root:root` and 60 `:global`/Mantine selectors (self-shell-nav 3.1) all exist because we fight a frame we do not own. The same rewrite must also fix what was our own API: the defects in section 4 "Rewritten" are basalt's, and a library swap alone keeps them.

## 3. Public API sketch

### 3.1 Declare, then mount

```ts
// src/lib/nav.ts, module scope: anchor identity keys on this object
export const NAV = defineNav({
  sections: [{ id: 'training', label: 'Training', items: [
    { id: 'overview', label: 'Overview', icon: Gauge, link: linkOptions({ to: '/' }), mobile: 'tab' },   // '/' is always exact
    { id: 'finance', label: 'Finance', short: 'Money', icon: Wallet, link: linkOptions({ to: '/finance' }), exact: true, mobile: 'tab',
      children: [{ id: 'month', label: 'Month', link: linkOptions({ to: '/finance/$month', params: { month: 'latest' } }) }] },
    { id: 'jobs', label: 'Jobs', icon: Play, link: linkOptions({ to: '/jobs' }), activeWhen: ({ pathname }) => pathname.startsWith('/runs') },
  ]}],
  pinned: [{ id: 'settings', label: 'Settings', icon: Cog, link: linkOptions({ to: '/settings' }), mobile: 'more' }],  // rail bottom
})

// src/routes/__root.tsx
<AppShell nav={NAV} brand={{ name: 'Argo', logo: Mark }} storageKey="argo-sidebar"
  badges={{ finance: { count: 3, attention: true }, jobs: { dot: true } }}         // keys typed from NAV, a typo is a compile error
  globalControls={filterSlot([rangeSpec])}
  globalActions={[{ kind: 'popover', id: 'bell', icon: Bell, label: 'Notifications', badge: unread, mobile: 'bar', content: (box) => <Inbox box={box} /> },
                  { kind: 'custom', id: 'timer', label: 'Timer', priority: 2, render: (box) => <TimerChip box={box} /> }]}   // counted escape, re-renders alone
  blocks={[{ kind: 'progress', id: 'quota', label: 'Quota', value: 0.7 }, { kind: 'custom', id: 'tree', mobile: { label: 'Library', icon: Tree }, render: (box) => <LibraryTree box={box} /> }]}
  settings={{ mode: 'menu', items: [{ id: 'lock', label: 'Lock', icon: Lock, onClick: lock }] }}
  account={account} search={{ onOpen: openPalette }} chrome="web">
  <Outlet />
  <ToastHost /><OverlayHost overlays={OVERLAYS} /><CommandPalette commands={COMMANDS} />
</AppShell>
```

`AppShell` props, 12 against 25 in 2.x: `nav` (required), `brand` (required), `badges`, `blocks`, `globalControls`, `globalActions`, `settings`, `account`, `search`, `storageKey`, `chrome`, `compactHeader: 'show'|'hidden'` (obsidian). Types: `NavBadge`, `GlobalAction` (`button`, `popover`, `custom`, each with `priority`, `mobile: 'bar'|'more'|'hidden'`), `NavConfig`. Extensions are typed data or box slots, no `ReactNode` regions (law C13).

- **`account`** is `{status:'loading'}`, `{status:'signed-out', onSignIn}` or `{status:'signed-in', name, detail?, avatar?, rows?, onSignOut?}`, shutterflow's three states. `detail` carries email or plan text, `rows` carries Manage account. Only the plan and role badge matrix goes.
- **`settings`** holds `onClick` items. A settings entry that is a router link (shutterflow) is a `pinned` nav item, so it gets `aria-current` from the resolver.
- **`NavItem.link`** is plain `linkOptions`; a click-time `search` function stays legal, and anchor identity keys on the `NavItem`, so a new closure never remounts. Route-owned keys need it: argo's calendar `date`, astro's `lp`, `wx`, `terrain`, which its composed validator makes required on the link. Store fields follow `controls-url-state` 4.5.
- **`custom`** receives `box: { height, sizeClass }` and is clipped to the header row. `sizeClass` is the frame axis, so a label change at the `expanded` boundary is legal without a JS layout twin; contract 7.3 counts it (section 9).

### 3.2 The page, in shell or not

```tsx
<Page area="photos" fill>
  {' '}
  {/* `area` scopes commands; `fill` = definite height */}
  <PageBar
    title={run.name}
    parent={{ label: 'Runs', href: navTarget({ to: '/runs' }) }}
    controls={filterSlot([rangeSpec, envSpec])}
    tabs={filterSlot([spec.tabs(store.field.view)])}
    refresh={{ scope: 'page', ...useFreshness(keys).button }}

  </PageAside>

```

`PageBar title` has one meaning everywhere, which fixes shell-17's silent ignore: in a shell it claims the breadcrumb leaf (`parent` likewise, rb's dynamic breadcrumb, `back-referrer.ts`, 70 lines) and names the in-flow sr-only `h1` and `document.title` (default: nav label); without a shell it renders the visible `h1`. `PageAside` `title` is required and is both header and `aria-label`.

`PageAction` is `{id, label, icon?, primary?, group?, onClick, mobile?}` or `{kind:'text', id, text, mobile?}`. At most one `primary`, none required: 2.x demanded one, which pushed argo's date nav into `filtersEnd` (argo-friction row 7). Items sharing a `group` render joined and fold together.

### 3.4 Router wiring and why no `staticData`

```ts
// src/router.tsx, written by `basalt-ui init`
const queryClient = makeQueryClient()
const { options, link } = routerDefaults()   // preload intent, preload stale 0, pending 300/300, structural sharing, scroll restoration, top selectors, transition types
export const router = createRouter({ routeTree, context: { queryClient }, ...options,
  Wrap: ({ children }) => <QueryClientProvider client={queryClient}>{children}</QueryClientProvider>,
  defaultPendingComponent: RoutePending, defaultErrorComponent: RouteError, defaultNotFoundComponent: RouteMissing })   // app files on `EmptyState`, seeded by `init --profile app`
declare module '@tanstack/react-router' { interface Register { router: typeof router } }
// main.tsx: <BasaltProvider link={link}><RouterProvider router={router} /></BasaltProvider>
```

- `./router` may not import Query or `ui/*` (contract L2), so `Wrap` and error screens live in the app's template. That also removes the prerender crash from default components (ext-tanstack hazard 3). Pending values are a trial (ext-tanstack 3.5). **Without a `defaultPendingComponent` the 300/300 timer never arms and nothing renders** (F, react-router 1.170.46 `Match.js:18`, router-core `load-client.js:702`), so `RoutePending` is seeded too. `RouteError` branches on a structural `status`: 403 forbidden, 401 the app's session path, anything else the crash copy; `doctor` check 12 fails when any of the three is unset.
- `navTarget(linkOptions)` returns an opaque `NavTarget`; the `link` adapter spreads it onto `Link`. The one cast lives there, so obsidian's `as never` dies. Router-free subpaths type `href: string | NavTarget`.
- **Against the digest:** gap-controls proved a portal is absent from server HTML while `staticData` is present. The conclusion "data-only slots move to `staticData`" does not follow: rendering in flow is also present, keeps "the page owns its filters and their stores" (self-shell-nav Q3), and leaves one authoring channel instead of two. Server presence is not the deciding reason, since no `app` consumer server-renders. Nested layouts each rendering a `PageBar` are a dev assertion (section 2), not a merge rule. `staticData.sidebar` is deferred, DPO 14; alternative route-declared rail blocks.
- Cost accepted: `--page-bar-h` becomes load-bearing for sticky children, and Main's scrollbar spans the band. It is written on `Page` for sticky children; `PageHost` mirrors it to the shell root because the aside is a sibling of Main. S1 measures both.

### 3.5 Anatomy, slots, chrome

| Region            | Element                         | `data-slot`                                                                                              | Size class behaviour                                                     |
| ----------------- | ------------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Skip link, header | `a` first focusable; `<header>` | `shell-skip`, `shell-header`, `shell-titlebar` (native), `shell-lead`, `shell-trail`, `shell-breadcrumb` | One height token at every width; landscape clamp 9dvh                    |
| Rail              | `<nav aria-label="Primary">`    | `shell-rail`, `shell-rail-footer`, `shell-rail-block`                                                    | Hidden compact; collapsed at medium, expanded at expanded, until `isSet` |
| Main              | `<main tabindex=-1>`            | `shell-main` (+ `data-scroll-restoration-id`), `page`, `page-bar`                                        | Container for every page tier                                            |
| Aside             | `<aside aria-label={title}>`    | `shell-aside`                                                                                            | 0 wide unclaimed; docked or overlay                                      |
| Footer            | `<nav aria-label="Primary">`    | `shell-tab-bar`                                                                                          | Compact only; owns the one bottom safe-area inset                        |

- **Default rail state is CSS** (`data-rail="auto"`), so server HTML is right for anyone who never toggled. CSR reads `persisted` on first render, no flash. localStorage, not a cookie: DPO 17, alternative cookie. Only SSR plus a toggled rail can flash, and no consumer has that today.
- **`chrome`**: `web` (default) or `native-overlay`, which sets header 52, `--chrome-lead-inset` 80, and makes `shell-header` a drag region: `data-tauri-drag-region="deep"`, `app-region: drag`, interactive children `no-drag`, replacing shutterflow's `querySelector`. macOS overlay first; a trail inset is additive with the first Windows consumer.
