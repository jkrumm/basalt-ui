# Concept: skills, rules and the agent layer (`agent/`, CLI `init` `sync` `doctor` `shot` `lint --agent`)

Date 2026-11-09. Contract: `ARCHITECTURE.md` (A§n). Evidence slugs as in the digest. Tags: **F** run or read (cited), **J** judgement, **U** unverified. `DPO 15.x` = DEFAULT-PENDING-OWNER, sub-items of A§12 rows 15 and 18, each with its one-line alternative (section 10). Rule ids, preset contents and the lint engine belong to the guardrail concept; this one owns what an agent meets: delivery, hook (registration, shim, seeded-offender fixture), teaching, DESIGN.md, reviewer, shot, docs and recipe artifacts. Revised the same day against an adversarial review: section 11 is the Review Log.

## 1. Decision summary

1. **The agent layer is the half of the product that is not Mantine's, and the half v3 must make portable.** About 85% of it is framework-neutral: method, rubric, shot harness, tagged-rule architecture, delivery (self-agent-layer 0.1). Epos and console took tokens and principles and none of the enforcement, then hand-rolled one raw-colour test each (F, same report 0.2): v3 wins them by making enforcement install with one verb, not by writing more prose.
2. **Premise challenged: "skills teach, rules guarantee" is right, but skills have the weakest evidence in the stack.** External: injected skills moved pass rate -1.3 to -4.2 pp, helped 17-36% of pairs, gain came from anti-pattern rules; Anthropic's frontend-design -1.8 vs none (ext-guard 6a, vendor and third-party numbers). Internal (F, trials v2-v7, n=1 each): score 31 to ~75 came from **fixing basalt-owned component defects each trial** plus one catalogue and anti-defaults reference; P1 fell 5, 4, 1, 0, 0, 0 while the count of basalt-owned findings did not shrink (self-agent-layer 5.2). So: component correctness first, diagnostics that name the fix second (shadcn evals: zero findings in one round, vendor numbers), a short method skill third, ceremony last.
3. **Two skills, five rules, one reviewer, one block.** `basalt-design` (method) and `basalt-app` (setup, migrate, upgrade); everything else is a reference under them (digest row 24: budget wins). Skills carry only judgement no linter sees: concept per screen, encoding choice, states, copy. Every sentence that can be a rule is a rule.
4. **Decision-time content goes where it loads at launch; procedure goes in a skill.** A `paths:` rule loads only when a matching file is read or edited, so it cannot reach an orchestrator designing a page before any file exists (row 223, F: Claude Code memory doc read today). The question-to-form table therefore lives in the AGENTS block (launch-loaded, <=10 lines); the charts rule keeps the detail for edit time. Skills failed three times (rows 135, 223, 224; self-agent-layer 5.4: 6/6 activation only in trial conditions, project root = app). **That this layout fixes 135 and 224 is U until S7 passes**; this concept claims no more.
5. **The edit-time hook is the delivery that matches the evidence, and it must fail loud.** `init` registers PostToolUse (lint the edited file, exit 2 with a fix-naming message), one Stop re-check, PreToolUse deny on `.basalt/**`, generated presets, shipped rules and the hook entries themselves; `doctor` pushes a seeded offender through it (DPO 15.1; A§9). F (Claude Code hooks page, read today): only exit 2 blocks or feeds the model, every other code is a non-blocking error, hooks run in the session's current directory which follows `cd`, `$CLAUDE_PROJECT_DIR` is the stable anchor. So the entry calls a managed shim (4.2) through a wrapped command (a bare `node ... <event>` fails open when the shim file, `node` or `CLAUDE_PROJECT_DIR` is missing; hook-sync S2, `spikes/hook-sync.md`) that resolves the bin from the project dir and maps every failure to exit 2. F: single-file lint 0.27 to 0.5 s (gap-guardrail 5). Shell-tool edits bypass it, so `make check`, `lint` and `sync --check` stay the gate.
6. **Managed agent files are rendered, then byte-compared.** F: all six of argo's installed rules differ from the shipped source on exactly one line, the rendered `paths:` entry (`apps/dashboard/src/**` for `**/src/**`); only the reviewer and `basalt-charts/SKILL.md` are byte-identical. So `sync` renders (`paths:` from declared roots) and writes, `sync --check` renders and compares, and the renderer is what S5 proves (S5 PASS 2026-11-11: zero false drift on six shapes once the formatter ignores the managed paths; the renderer sorts the roots; `sync` resolves shipped sources from the manifest's package directory). Normalised hashing, the three-way prune and the legacy-hash path die. Whether an edited managed file is clobbered or reported is settled once, in guardrails E1 (raw-byte digest of the rendered file in `manifest.managed`, edited = left and reported, `--force` finishes); this concept follows it (DPO 15.2). Consumer intent lives in `DESIGN.md`, never in a managed file.
7. **Docs are a generated artifact, not a skill.** One extractor (gap-repo, P0-14) writes `docs/<export>.md` and `llms.txt`; skills link, never restate props. Metric: `.d.ts` look-ups per trial run, 6 to 14 across v2-v7 (8, 14, 6, 6, 9, 10; the 17 was v1, a different task), no numeric target. `llms.txt`, a signature file, never got it to 0, and generated per-export docs are the same class of artifact (F, self-agent-layer 5.x); only owned source removes the class, and the stat and table composites are not source-owned (A§10 J3 override). S1 therefore carries a fail line: look-ups at or above 6 with generated docs means composite docs carry the full prop table inline, or the composites become source-owned. Examples are marked regions of the compiled playground, so they cannot rot (section 4.5, S3).
8. **`shot` is a floor, re-pointed and trimmed.** It reads public `data-slot`s and `--vx-*`/`@theme`, needs no consumer attribute on library composites, and never produces a quality score: the detector scored 100 on boards with 17-19 defects (self-agent-layer 0.4, F), and its contrast check duplicates axe, so contrast leaves `detect`. Viewports are declared per profile, not hard-coded (a desktop-only app is a first-class consumer). The real-data proxy, `--auto-anchors` and `--api` stay only if a second named consumer exists by the next minor (adopt-or-delete). The reviewer owns judgement, advisory, calibrated on seeded boards.
9. **The reviewer gets a tool-neutral rubric, a diff mode and a no-subagent path.** Rounds end on "no regression, no carried P1", not "three rounds" (rows 224, 229). Severity counts are the verdict; the 0-100 stays as a computed field for trial comparability, never a target. A builder without the Agent tool cannot skip the reviewer silently: `shot` records the round and the Stop re-check names an unreviewed round (5, S7).
10. **DESIGN.md is intent, not reference, and no longer `@`-imported.** F: argo's is 363 lines, 34 KB, loaded into every session through `@./DESIGN.md`, and its Identity states v2 doctrine as the top-precedence law (cool zinc, hex `#0077bd`, "Use Mantine primitives", "collapses Mantine's raw ramp steps"); about 230 lines are a series dictionary that duplicates `src/lib/series.ts`. Atlassian's one test: an 80 KB DESIGN.md cost +72% tokens (ext-guard 6b, "not conclusive"). So: Identity is a generated region (cannot disagree with the derive config), the series table lives in `src/basalt.tokens.ts`, Direction (character, world, moments, signature, what never to repeat) is owner-written and left empty by `init`, deviations may narrow or add and never relax a rule bullet, and the file is read on demand by `/basalt-design`, not imported.
11. **No registry and no MCP server at 3.0** (A§10, DPO 18), and no frontmatter designed for one: it would be speculative until the trigger in 4.6 fires, and the extractor's frontmatter is additive anyway. `shadcn mcp` and the shadcn skill co-exist under a stated precedence: the narrowest guarded owner wins, written as a paragraph in the managed `basalt-design` skill preamble, its surface list regenerated from the v3 rules (the basalt surfaces are shadcn-based, not 2.x composites; S6 PASS 2026-11-11: 16 pairs ordered by one rule, no unmatched topic, `spikes/hook-sync.md`).
12. **The one-look guarantee survives take-what-you-want**: every profile from `bridge` up installs the same preset, hook and tokens rule; `one-look` (A§9) proves sameness, not beauty.
13. **Skills get a kill criterion before they get a build.** The evidence is thin (decision 2), so S1 runs a thin skill (one `basalt-design` SKILL.md plus the anti-defaults reference) before issues 7-10. Kill rule: with-skill removing fewer than 3 P1-plus-carried findings against no-skill drops the references into the generated docs and the rules; the bar is in P1 and carried-finding counts, never a ~75 score (15.3). **S1 ran 2026-11-11 (`spikes/thin-skill.md`): Kill yes (2 removed, 3 needed; 12 single runs), so the kill is applied.** The references move into rule messages, the hook's findings and generated docs (`anti-defaults.md` token and lint rows become the rule set, `states.md`-style copy rules go into the generated docs); the skill that remains is method only and links, and its `use when` is not empty. Generated docs carry what the `.d.ts` cannot say (when to use, never when, the slot a figure goes in), because only 2 of 6 skill-on agents followed a link to a doc. The table (layout class) is not touched by a skill, hook or lint: a typed-frame candidate to re-run with frames before it is built. The owner's taste check of the brief-1 shots is PENDING and does not hold the kill.
14. **Recipes are a channel, not a skill reference.** A§10 cuts exports on "a 20-line recipe does it"; that is only honest if the recipe exists, compiles and is findable. One generated channel, `docs/recipes/<name>.md`, owns them (3.16).

## 4. Public API sketch

### 4.1 CLI behaviour (eight verbs, A§4.3; unknown flag exits 1 except under `--hook`, `--help` never mutates, local bin never `bunx` except `init`)

```text
basalt-ui init --profile tokens|bridge|parts|app   # manifest, peers for the profile, installs, patches vite/css only when the shape is recognised, else prints the exact lines;
                                                   # at the git/workspace root: .claude/{rules,skills,agents}, AGENTS block, DESIGN.md seed, settings.json hook entries, .basalt/hook.mjs, formatter ignore; ends by running doctor
basalt-ui sync [--check]       # byte-for-byte placement of managed files, preset, rules; prune retired names; --check writes nothing, exit 1 on any difference
basalt-ui doctor               # <=12 checks, each pass | fail | SKIPPED (SKIPPED exits non-zero): section 4.3
basalt-ui lint [--file p | --changed | --stats] [--agent] [--hook <post-edit|stop|pre-edit>]
                               # --agent = terse, fix-naming, exit 2 on findings; --hook reads the event JSON on stdin, is called only by the shim, exempt from invariant 1;
                               # exit 1 on a waiver or eject ceiling breach (.basalt/budget.json); the one flag shape the guardrail concept's `--file <path>` yields to, because the path arrives on stdin
basalt-ui shot <routes> --dist <dir>|--base <url> --out <fresh dir> [--viewports 1800x1200,390x844] [--states empty,loading,error] [--auto-anchors] [--api /api=<origin>]   # viewports default to manifest.viewports
basalt-ui shot detect <out>    # floor: exit 0 clean, 2 findings, 1 scan failure
basalt-ui migrate --from X --profile P [--json] [--check]   # rows from migrations/*.json
```

The `command` strings above are shown bare for reading. The registered form wraps each one so a missing shim fails loud: `node "$CLAUDE_PROJECT_DIR/.basalt/hook.mjs" <event>; s=$?; case $s in 0|2) exit $s;; esac; echo 'basalt hook: the shim did not run (exit '$s'). Run bun install, then basalt-ui doctor.' >&2; exit 2` (`spikes/hook-sync.md`; the bare form fails open).

`hook.mjs` (managed, <=50 formatted lines, restated from <=40: the spike stub is 57 formatted lines, about 8 of them spike-only, `spikes/hook-sync.md`; the alternative is moving the output cap into `lint --hook`) resolves the bin from the manifest's package dir (bun's isolated linker puts it beside the dependent package, not at the root: basalt's own lefthook preset records that silent zero-scan), runs `basalt-ui lint --hook <event>`, and maps every outcome other than 0 or the child's own exit 2 to exit 2 with a line naming the fix (`bun install`, or `basalt-ui doctor`); a missing bin is the usual fresh-worktree case (argo AGENTS: a fresh worktree needs `bun install` first). The Stop pass is bound per turn by `stop_hook_active` (true while Claude continues because of a stop hook), and keeps a per-session counter keyed by `session_id` as a ceiling, not the bound: the counter alone gives one re-check per session and silences every later turn; with no `session_id` it does not block; if the owner run shows the field absent, the counter is the fallback (ext-guard 5; hook-sync S2); it also reports a shot round with no matching reviewer record (5).

**Merging `settings.json` (consumer-owned JSON).** `init` and `sync` parse it, identify basalt entries by `.basalt/hook.mjs` in the command, add or replace only those in place, and leave every other entry untouched (shutterflow's PreToolUse live-library guard and its tests stay as they are; re-serialising costs lines on a hand-formatted file, so splice text if that churn matters); a migrate row removes the legacy marker-less `bunx basalt-ui guard-hook` entry (rb). Unparseable JSON: print the entries, write nothing. `sync --check` parses and compares the basalt entries only. A finding line: `src/pages/a.tsx:41 basalt/class-policy: p-4 on <Section>; Section owns spacing. Use gap on the parent, or eject (basalt-ui eject section --reason).` Every message names the next rung (A§7.3).
