**Premise challenges (evidence, F unless marked).**
(a) "jkrumm.com is the cheapest consumer, about 3 days" (consumer-jkrumm-com 6) holds only if the accent decision is made first: the site's `#0084d1` is HCT 268/48/53, outside the fill band (tone 47.6) the engine pins; the shipped hex is a function of hue + vibrancy (`#4374a6` today, `#2e75b1` at vibrancy +1, `#0076bf` at +2, gap-token 6). "Must not desaturate" is an eye call on C, not an arithmetic one. (b) The sentinel-hex swap in jkrumm's `chart-palette.ts` implies SVG attributes cannot carry `var()`. Spike B: Chrome 157 resolves `fill="var(--vx-accent)"` and follows a scheme flip live. The swap is a workaround for Observable Plot's colour handling (U), not a platform limit. (c) FRAMEWORK-FREE.md never mentions `color-scheme`, and the emitted sheet has none (grep, section 8 P4): native scrollbars and form controls stay light on a dark page unless the emitter sets it. (d) "13 of 234 friction rows are Mantine" is irrelevant to D0, but D0 is not isolated from D3 apps: argo and shutterflow depend on D0 seams (scheme persistence, literal hex, head metas), which the first draft ignored. (e) "Only argo used BP, `p()`, the 12 fill families" is an argument for a replacement, not for dropping: argo is the largest consumer (section 3 row 10).

## 4. Public API sketch

### 4.1 CSS entries (frozen per major) and the script

```css
/* jkrumm.com, route (a): shipped identity. Needs a CSS bundler (Astro/Vite) for the font @imports. */
@import 'basalt-ui/fonts.css'; /* @font-face only; fontsource woff2 are bundled, unused weights are not */
@import 'basalt-ui/tokens.css'; /* UNLAYERED on purpose: the :root[data-theme] 0-2-0 law needs it (spike A) */
@import 'basalt-ui/typography.css'; /* @layer basalt.type  : vars + :where(:root) base */
```
