# State cycle 1

One data page built on master's published surface: an orders list with four URL filters, a table and a chart of the same query behind `ViewTabs`, a pushed live query bound to a channel, a connection indicator, and a row that opens an edit form with a draft, validation, `toSubmitErrors` and `FormFooter`. Then the user actions of the brief, run in Chrome against the playground build. Protocol: `docs/v3/CYCLES.md`.

The cycle has not converged: 4 P1, 11 P2 and 5 P3. Filters, view and record all round-trip through the URL: share, reload and back/forward put the page back exactly, and no action left the URL and a control disagreeing. The P1s sit around that core. A v3 app on `createBasaltRouter` cannot run `liveQuery` at all (state-1.1). `spec` refuses the multi-select and the date range at the type level (state-1.2). A second Escape in the status pill drops a filter the user had applied (state-1.3). A reload that restores a changed amount draws the form without its Status and Amount row (state-1.4). The app wrote no `useState` and no manual URL read. It did write about 44 lines of glue the kit could own.
