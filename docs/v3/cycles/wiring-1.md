# Wiring cycle 1

A fresh Vite and TanStack Router app, built outside the repo from the packed tarball, taken from an empty directory to two pages (an AppShell with one `StatCard` on `/` and one `DataTable` on `/orders`) by following only what ships: the README, `basalt-ui init` and `doctor`, the managed AGENTS block, the placed rules and skills, `docs/*.md` and `llms.txt`. Then a consistency read of the export surface. Protocol: `docs/v3/CYCLES.md`.

The cycle has not converged: 5 P1, 8 P2 and 8 P3. The kit itself held up once it was wired: the first `vite build` and `tsc -b` were green, both pages rendered with no console error, and `basalt-ui lint` found nothing. The cost sits in front of that. `init` declares a router scaffold (`main.tsx`, `__root.tsx`, `_app.tsx`, `nav.tsx`, three route components) and writes none of it (wiring-1.1), and the README and `llms.txt` an author reads first still describe the 2.x Mantine app (wiring-1.2), so the entry file was pieced together from a `.d.ts` example. On the rendered pages, a linked `StatCard` navigates by a full document load (wiring-1.3) and only from its header band (wiring-1.4), and at 390 px the table squeezes the row's name to 14 px (wiring-1.5).
