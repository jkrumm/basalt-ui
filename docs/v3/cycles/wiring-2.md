# Wiring cycle 2

A fresh Vite and TanStack Router app, built outside the repo from the packed tarball, taken from an empty directory to two pages (an AppShell with one `StatCard` on `/` and one `DataTable` on `/orders`, the same two pages as cycle 1) by following only what ships: the README, `basalt-ui init` and `doctor`, the managed AGENTS block, the placed rules and skills, `docs/*.md` and `llms.txt`. Then a consistency read of the export surface. Protocol: `docs/v3/CYCLES.md`. It reruns cycle 1 (`docs/v3/cycles/wiring-1.md`) on its nine fix rows, all closed done.

The cycle has not converged: 3 P1, 5 P2 and 6 P3. Cycle 1's front-of-house cost is gone: `init` writes the entry, the layout, the nav and the route components, patches `vite.config.ts` and `index.css`, installs the app peers, and the README and `llms.txt` teach the v3 app. The author wrote 62 lines, all of them the app's own, where cycle 1 wrote or copied 170, and read package code twice, both times after the pages rendered. A linked `StatCard` now navigates in the same document from any point on the card. What is left sits in the defaults an app inherits without reading them. The scaffold's route files export their component and say the lint requires it, and an app that follows the pattern ships one 861 kB chunk with `autoCodeSplitting` switched on (wiring-2.1). TanStack Router's generated `routeTree.gen.ts` fails doctor check 11 on every app once it builds, and nothing an author can do clears it (wiring-2.2). The phone table's fix lives in `basalt-ui/table.css`, which one sentence in one doc asks for; without it the 390 px table is cycle 1's 14 px name column again, and every gate is green (wiring-2.3).
