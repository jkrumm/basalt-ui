# Wiring cycle 3

A fresh Vite and TanStack Router app, built outside the repo from the packed tarball, taken from an empty directory to two pages (an AppShell with one `StatCard` on `/` and one `DataTable` on `/orders`, the same two pages as cycles 1 and 2) by following only what ships: the README, `basalt-ui init` and `doctor`, the managed AGENTS block, the placed rules and skills, `docs/*.md` and `llms.txt`. Then a consistency read of the export surface. Protocol: `docs/v3/CYCLES.md`. It reruns cycle 2 (`docs/v3/cycles/wiring-2.md`) on its six fix rows, all closed done.

The cycle has not converged: 1 P1, 2 P2 and 4 P3. Every one of cycle 2's 14 findings is fixed or partly fixed. The scaffold now splits by route (a 316 kB entry where cycle 2 shipped one 861 kB chunk), the generated route tree no longer fails doctor, the phone table reaches the app with no import of its own, and `init` keeps an in-range peer and deletes create-vite's dead demo. For the first time doctor ends at its floor: 12 pass, 0 fail, after the pages render, with lint at 0 errors and 0 warnings on the first run, and the author read no package code. What is left is one trap in the wiring: create-vite's own `build` script runs `tsc -b` before Vite, so it fails right after `init` and again after every new route, on a route tree the router plugin has not yet written, while doctor reports all 12 checks green (wiring-3.1). On the surface, the frame's value types (`Empty`, `Phase`, `Delta`, `Status`, `Tone`) have no v3 subpath, and the root barrel the docs send them to carries a 2.x `Tone` that rejects a tone the table accepts (wiring-3.2). On the page, a money column's own header truncates in its fixed width beside 1,000 px of free row (wiring-3.3).
