# Consumer audit: jkrumm.com (static Astro, no basalt-ui dependency)

Repo `~/SourceRoot/jkrumm.com`, HEAD b6ec0b4 (2026-11-08), 69 commits, 68 files in `src/`, 5158 lines across components/layouts/scripts/css. Measured 2026-11-09 against basalt-ui 2.29.0 (`dist` build in this checkout). F = observed fact, J = my judgement.

## 0. Headline

F: jkrumm.com imports **nothing** from basalt-ui. `package.json:23-42` has 9 dependencies and 6 devDependencies, no `basalt-ui`. It hand-ported basalt v1.2.0 colour values and design laws into `src/styles/global.css` (header `global.css:10`) and decided "do not install" in July 2026 (`docs/basalt-astro.md:9-10`).
F: three of the four stated blockers were fixed in basalt 1.20 to 1.21 (selector options, optional peers, `tokens:css` CLI with `--only core`; see `docs/FRAMEWORK-FREE.md`), and the site did not re-evaluate. `docs/basalt-astro.md` still describes v1.2.0 and the "What would have to change" table (`docs/basalt-astro.md:208-224`) is now largely shipped. Nobody told the consumer; there is no change feed from basalt to non-adopting consumers.
J: this is the cleanest evidence that the biggest barrier to a "take what you want" framework is not missing features but **missing discoverability and a one-shot adoption path** for the CSS-only layer.

### Missing (v3 should own)

1. Zero-install CSS entry (`@import 'basalt-ui/tokens.css'` / `typography.css` / `prose.css`) with scheme selector configured by a CSS custom property or data attribute, not a CLI flag.
2. Accent retune without React; resolve the spec/emitter drift as one decision.
3. Type ladder, weights, heading reset, rhythm tokens, motion tokens as CSS.
4. Plain-class prose and a minimal MDX component contract that Astro/MDX can render (Callout, Steps, Kbd, Figure, PullQuote, Table are all re-invented here).
5. Chart colour tokens addressable from build-time SVG; sequential ramp.
6. Lint/guard that runs on `.astro`, `.css`, `.mdx` with the tokens-only profile, including spacing/px/border laws.
7. A shipped agent skill + rule for "static site on basalt" (the site had to author its own `astro-motion-scroll` skill and `animation` rule).
8. A consumer-update channel (`basalt-ui doctor` equivalent for non-adopters, or a note in `MIGRATING.md` of what became possible).

### Leave to the app

Layout grid (rail/column/measure), the hover vocabulary, reveal and scroll motion, Umami events, print/paper system, career data model, fonts beyond the three defaults, dev-toolbar labs, content collections, the choice to be borderless (hairline budget numbers).
