# Consumer audit: rb (basalt-ui 2.29.0, Mantine 9.7.2)

Repo `~/SourceRoot/rb`, 255 commits, web = `apps/web/src` (45 non-test source files, ~12.5k lines TS/TSX/CSS, 14 test files, no DOM test stack). Private single-user learning tracker, Bun/Elysia + static React SPA, tailnet only. Paths below are relative to `~/SourceRoot/rb` unless noted. Method: grep/python census over `apps/web/src`, `git log`, `docs/waves/**`, `oxlint .` and `check-theme` run read-only (both green, 0 basalt warnings; the 78 warnings are generic unicorn/react lints, see §2).

Fact = observed. Judgement = marked "J:".

## 0. Shape of the app (why it matters for v3)

rb is the **small, content-reader, forms-light** consumer: 10 routes (`lib/router.tsx:21-110`), ~498-item catalog, no charts, no data table, no realtime beyond polling, no SSR, no global command palette. It is the cleanest proof of the "shell + nav + URL-state filters + content prose + settings composites" slice, and says almost nothing about charts, tables, virtual lists, forms, AI streaming.
