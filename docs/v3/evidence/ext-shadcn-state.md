# Evidence: shadcn/ui state, Nov 2026, and how others build a framework on it

Researched 2026-11-09. Read-only except this file. Sources: installed `shadcn@4.23.0` + `@shadcn/registry@0.2.1` under `~/SourceRoot/software-factory/node_modules/.bun/` (minified, so cited by file + symbol, line 1), live registry JSON (curl), `gh api`, `npm view`, `agw research`/`agw web read` (URLs inline). **Fact** = observed/cited. **J** = my judgement. **U** = unverified. SF = `~/SourceRoot/software-factory`. Companion files: `shadcn-factory-console.md`, `shadcn-epos-teamchat.md`.

## 0. Headline

1. shadcn is no longer "copy components". It is a **registry protocol + preset system + agent surface** (CLI 4.23.0, 2026-10-27): 3 bases (Base UI default since 2026-07-02, Radix, React Aria), 8 styles, preset codes, `apply`, `eject`, GitHub-source registries, a first-party agent skill and MCP server. Fact.
2. **Nobody serious ships a compiled component package on top of shadcn.** All 8 comparable projects below distribute as registries (copy-in); the only hybrids split _behaviour in npm_ from _look copied_ (assistant-ui; shadcn itself now: `cn`, `shadcn/tailwind.css`, `@shadcn/react`). Fact.
3. **The update story for copied code is the unsolved weak point**: no version field on items, no lockfile, `add` on an existing file = yes/no overwrite prompt, `--diff` is two-way. Everyone compensates with changelogs + agents. basalt-ui already owns something better (sha256 ledger, three-way `classify`). Fact + J.
4. **Nobody enforces; everyone teaches.** shadcn's own skill carries ~25 lint-shaped rules ("no `space-y-*`", "no raw colors", "Dialog needs a Title") as prose; no lint package exists in `shadcn-ui/ui/packages` (`helpers react registry shadcn tests`). coss ships a skill + AGENTS.md, Biome generic. The "guarantee" column is empty in the market: that is basalt's niche. Fact + J.
5. **Mobile-first density is solved inside the primitive in the best project (coss)**: `h-9 sm:h-8`, `pointer-coarse:` hit areas, `loading` prop in Button. shadcn base-nova is desktop-dense only (`h-8`). J: copy coss's mechanism, not shadcn's.
6. **Data table**: shadcn ships a _guide_, not a component ("Every data table I've created has been unique"); TanStack Table is now **v9** (9.3.1, feature-based `tableFeatures`); the strongest public implementation is ReUI `data-grid` (12 files, ~416 KB). Fact.

## 4. Registry mechanics (what a framework can use)

| Mechanism                           | Fact                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Item types                          | `chunk-G4XCG644.js` enum `o`: lib block component ui hook page file theme style item **base** font example internal. Docs: `registry:base` = "entire design systems"                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Item fields                         | `$schema extends name title author description dependencies devDependencies registryDependencies files tailwind cssVars{theme,light,dark} css envVars meta docs categories`. **No `version` field.** `dependencies` accept `name@1.2.3`. `registryDependencies` accept `name`, `@ns/name`, full URL                                                                                                                                                                                                                                                                                               |
| `registry:base` + `extends: "none"` | CLI `index.js` `ye()`: `registryBaseConfig = item.config` if `type==="registry:base"`; `installStyleIndex = item.extends !== "none"`. `config` is a partial components.json (style, tailwind, iconLibrary, aliases, registries). ## 5. Base UI vs Radix vs React Aria (as it matters for v3)

- Fact: shadcn changelog `2026-07-base-ui-default`: new projects default Base UI; "projects created on shadcn/create pick Base UI over Radix 2 to 1" (their claim, **U**); Radix supported indefinitely; both coexist per component.
- Fact: coss is Base UI only "not as a port from Radix" (`https://coss.com/ui/docs`); Dice UI defaults Base UI; assistant-ui/ReUI/Shadcn Studio/Shadcnblocks ship both via the `{style}` placeholder; Kibo, prompt-kit, shadcn-admin, Tremor Raw are Radix (agw research, `r2`).
- Fact: Base UI API differences visible in sources: `render` prop + `useRender`/`mergeProps` (coss button, SF console `kit`) instead of `asChild`; `data-open/closed/checked` attrs; per-component subpath imports `@base-ui/react/button`, all `sideEffects:false`.
- J: choose **Base UI only** for v3 (one primitive family to lint, teach and test; the whole ecosystem of Base UI registries, coss, Dice, ReUI `base-*`, is directly reusable). Keep React Aria out unless a gap forces it (date/calendar, color). Radix would double the rules and skills for zero gain.
- Gap list for a data-dense app on Base UI + shadcn alone: sidebar/shell (shadcn sidebar is one 731-line file, JS breakpoint), data table (guide only), charts (recharts, conflicts with TanStack-Charts-only), command palette (cmdk 1.1.1 last release 2025-08-27, **U** whether alive), calendar (react-day-picker), toast (Base UI Toast 4.14+ now default for Base projects, `sonner` for Radix/Aria per the skill), resizable (react-resizable-panels), forms (shadcn `Field`/`FieldGroup` + RHF/TanStack Form guide).

### 6.1 coss in depth (closest analogue to a dense, opinionated, Base UI framework)

- Source of truth `apps/ui/registry/default/{ui,lib,hooks,chat,particles}`; `scripts/sync-ui.mts` copies + rewrites imports into `packages/ui/src/{components,lib,hooks,chat}` (the workspace package `@coss/ui`, `package.json` `exports` map raw `.tsx`: `./components/*`, `./hooks/*`, `./globals.css`), which Biome **excludes from lint** (`biome.json` `files.includes` `!**/packages/ui/src/components`). `registry:validate-deps` checks that each item's declared deps match its imports. (gh `cosscom/ui` `apps/ui/package.json` scripts, `packages/ui/package.json` exports, `biome.json`.) Fact.
- Button (`https://coss.com/ui/r/button.json`): `size.default "h-9 ... sm:h-8"`, `icon "size-9 sm:size-8"`, `pointer-coarse:after:` hit-area expander, built-in `loading` + `Spinner`, `render`+`mergeProps`+`useRender`, `data-pressed`. Mobile 36px / desktop 32px, **no consumer effort**. Fact.
- Tokens: shadcn set + `--success --warning --info --destructive-foreground`; borders as `--alpha(var(--color-black) / 8%)` + inset shadows "for crisp borders even when backgrounds lack contrast"; fonts `--font-sans/--font-heading/--font-mono`; "color system is optional, but conventional tokens give inconsistent results" (`https://coss.com/ui/docs/styling`). Fact.
- Teaching: `apps/ui/skills/coss/SKILL.md` ("Do not invent coss APIs", "prefer styled exports over `*Primitive`", "Sheet replaced by Drawer, do not introduce Sheet") + `references/{rules/{styling,forms,composition,migration}.md, primitives/<55>.md, component-registry.md}`; `apps/ui/AGENTS.md` = particle authoring rules ("always `export default function Particle()`", icons never get numeric `size`, prefer `opacity-64` multiples of 8) + `https://coss.com/ui/llms.txt`. Guarantee = types + Biome; **no custom lint**. Fact.
- Layering vocabulary: primitives (Base UI + styling) → particles (assembled patterns) → atoms (API-connected). Fact (`https://coss.com/ui/docs`).

### 6.2 ReUI data-grid (headline item reference, cite for the data-table agent)

`https://reui.io/r/base-nova/data-grid.json`: 12 files, 416 KB source (`data-grid-table.tsx` 113 KB, `data-grid-cell-selection.tsx` 98 KB, `data-grid.tsx` 52 KB, `-table-virtual` 37 KB, `-table-dnd-rows` 31 KB, column-header 21 KB, ...), deps `@tanstack/react-table` (v9 `tableFeatures`/`createXRowModel`), `@tanstack/react-virtual`, `@dnd-kit/*`, `@base-ui/react`. `data-grid.tsx` carries `"use no memo"` (opts out of React Compiler: row/column builder reads keep identity across renders). i18n object, spreadsheet-style `onCellsChange` (paste/fill/clear), column filter/visibility/pinning/resizing/DnD. Plus `filters*` (13 items: operators, query, builder, chips, draft) and `gantt*`, `kanban`, `event-calendar*`. Fact. ## 10. Judgement for v3 (flagged J; owner decides)

1. **Hybrid, with a managed copy-in layer for the visual primitives.** npm `basalt-ui` keeps what is logic and law: tokens CSS + Tailwind `@theme` bridge, state/query/URL/forms modules, chart host + TanStack Charts glue, table engine glue (headless, TanStack v9), shell logic hooks, the oxlint plugin, skills, rules, CLI. The ~40-60 styled Base UI primitives (button, input, dialog, popover, tooltip, select, tabs, card, badge, ...) are **source in the consumer repo**, placed by `basalt-ui init/sync` through the existing ledger, shaped as a shadcn-compatible `registry:base` (`extends: none`) so `shadcn add @basalt/x`, `shadcn docs`, the shadcn skill and MCP also work. Evidence: it is the shape shadcn itself converged on, it is how assistant-ui splits, and the Console + epos both already build on exactly that substrate (`shadcn-factory-console.md` §2, `shadcn-epos-teamchat.md`).
2. **Decide "owned vs managed" per layer, explicitly**: shadcn/coss say "you own it, edit freely"; basalt's value is enforcement. Proposal: primitives are _managed_ (`doctor` fails on `drifted` unless the file carries an explicit eject marker), consumer composites live outside the managed dir and are fully free and fully linted. This is the only way "take what you want yields one look" survives copy-in.
3. **Do not use `shadcn apply` / `init --preset` on a basalt project**: it "reinstalls components" (changelog `2026-04-shadcn-apply`) and would clobber managed files; ship `extends: none` and document it in the rules.
4. **Density and mobile live in the primitive** (coss pattern: `h-9 sm:h-8`, `pointer-coarse:` hit area) plus a token for it, not in per-page code; base-nova's fixed `h-8` is what the Console had to patch (`shadcn-factory-console.md` §3: `size-11 md:size-8`, unused `--vx-hit`).
5. **Lint plan**: native `no-restricted-imports` (stable) for primitive boundaries; basalt oxlint plugin (already production, alpha-risk accepted since 2.x runs on it) for className analysis (arbitrary value, raw palette, `space-*`, raw breakpoint, status-as-text, structure rules like Dialog-needs-Title); `better-tailwindcss` `no-unknown-classes` as an optional ESLint-only CI step if oxlint compatibility is not proven. Pin oxlint; alpha API can break.
6. **Teach** with the same triple shadcn+coss converged on: skill (workflow + Incorrect/Correct pairs), per-primitive reference files, `llms.txt`/`.md` docs; add `evals.json`-style checks (shadcn ships `skills/shadcn/evals/evals.json`). Distribute rules/skills also as a GitHub-registry `registry:item` with `~/` targets (June 2026 feature) in addition to `basalt-ui sync`.
7. **Base UI only**; React Aria and Radix out.
8. **Charts**: shadcn `chart` = recharts; skip, TanStack Charts stays. **Data table**: do not copy ReUI/Kibo; the logic is an npm module on TanStack Table v9, the table chrome is managed primitives.
