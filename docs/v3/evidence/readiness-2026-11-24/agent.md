# basalt-ui 3.0 readiness: shipped agent layer

Scope: `packages/basalt-ui/agent/**` (3 skills, 5 rules, reviewer + rubric, templates) read as a fresh agent with only that layer plus `node_modules/basalt-ui/docs`. Read-only audit; nothing built or run. Paths below are relative to `packages/basalt-ui` unless absolute.

## Verdict

The layer is structurally sound and unusually well guarded: every lint id and every `[type:X]` tag in the five rules resolves (18 lint ids, all type names checked), every `node_modules/basalt-ui/docs/*.md` link the skills use resolves, and a scan of every camelCase/PascalCase identifier in the skills found no invented API. It is not ready to freeze as it stands, for three reasons. (1) The AGENTS block, the only always-loaded pointer, no longer names `/basalt-charts` (removed in 645316b21, 2026-11-13), which is exactly why a trial never loaded it. (2) A handful of confidently wrong claims about code that the guards do not reach (they check names and import specifiers, not props, flags or numbers): bulk action shape, `doctor --from`, the DESIGN seed's config knobs, the LucideProvider scaffold. (3) About 225 KB of references are written as audit history ("one page printed...", a private product name, GitLab MR ids), which costs tokens on every build and leaks process context into a public npm package.

## Sound (brief)

- Rules: each bullet cites a resolving lint id or type, or sits under `not guarded:`; enforced by `scripts/check-rule-tags.ts`. Sizes 2.6-4.9 KB, `paths:`-scoped.
- Drift guards that exist and work: `check-agent-doc-drift.ts` (names, import specifiers, removed-API denylist), `design-references.test.ts` (PascalCase names and `name (`path`)` pairs), `skill-references.test.ts`, pack-test file list.
- Delivery model: skills, rules, reviewer and AGENTS block are managed files with three-way sync, `--check` for CI, ejects and blocks merge instead of overwriting. Skills are copied into `.claude/`, so relative `../basalt-design/references` links work.
- Hook design is right: fail-closed, edit-time lint with the fix text, a once-per-session Stop re-check, and a pre-edit denial of weakening edits to the preset.
- basalt-charts and linked-parts.md are accurate and procedure-shaped; migrate.md's four coexistence shapes are decision-grade.
- Reviewer + rubric: fail-closed rules, diff mode and the `last.json` contract are consistent with `shot` and `shot detect`.
- Description sizes are well inside budget; `when_to_use` for charts names the right moments.
