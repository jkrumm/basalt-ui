# basalt-ui v3 readiness: lint rules, guards and CLI

Scope: `src/lint/**`, `src/cli/**` (init, sync, doctor, lint, eject, budget, hook), `agent/templates/hook.mjs.tpl`,
`src/vite/**`, `.basalt/{manifest,budget}.json`, `agent/rules/*.md`. Read-only audit of master at 2fed04240, nothing
built or run. All paths are relative to the repo root.

## Verdict

The lint layer itself holds up and can freeze. There is one rule table, the presets are generated from it, every
form has a fixture that runs under both ESLint and oxlint, the class rules work on the AST, and every `[lint:id]` in
the shipped rules resolves. What does not hold yet is everything around the rules once they sit in a consumer's repo:

- `sync` cannot refresh the hook it depends on.
- The pre-edit guard forbids the manifest edits the shipped skill tells the agent to make.
- The waiver budget fails the first legitimate waiver.
- Three decisions the stock-take recorded (rows 6, 9 and 10) are still undone.

These are P1 because each one is either written into consumer files or exported at 3.0. The P2 rows are cheap traps:
the CLI runs on Bun only and says so nowhere, oxlint is not declared as a peer, two waiver counters disagree, and a
tarball gate still checks a dead 2.x file list.

## Answers to the seven questions

1. **Ids.** The plugin has 19 ids, which is exactly `ID_CEILING` (`packages/basalt-ui/src/lint/rule-table.ts:18`). The agent rules
   cite 18 of them. The only one uncited is `logical-properties`, which runs in the site profile only. No rule cites an
   id that does not exist. The ids still use the British `colour` spelling (P1-4). Every basalt rule is `error` in
   every preset; there is no warn tier:
   - bridge: 9 basalt rules
   - parts: 17 basalt rules plus `no-use-before-define`
   - app: 18 basalt rules plus `no-use-before-define`
   - site: 10 basalt rules
   - all four: the 6 shadcn rules on top
2. **Tests.** Every form has a fixture with a valid and an invalid block. Each block runs under ESLint's `RuleTester`
   and under oxlint `plugins-dev` (`packages/basalt-ui/src/lint/rules/structure/colour-literal.test.ts:37-60`, `:92-100`), and
   `factory.test.ts:89` checks that the plugin's rules equal the table. The class rules read only class contexts on
   the AST (`packages/basalt-ui/src/lint/factory.ts:10`), so a regex over raw source is not a false-positive risk. The real
   false-positive risks are in the counters (P2-4) and in `no-use-before-define`, whose known bad case is documented
   at `packages/basalt-ui/src/lint/preset.ts:36-40`. That bad case needs a waiver, and the waiver budget starts at 0 (P1-3).
3. **Formats that freeze.**
   - `manifest.json`: no format field, but it keeps unknown keys (`rest`).
   - `budget.json`: no format field, and it drops unknown keys when it rewrites.
   - `sources.css`: generated and gitignored, so it can change freely.
   - Hook entries: written by `init` only.
   - Eject header and `ejected` rows: not marked experimental.
   - `sync` has no format migrations. `migrate` covers 2.x, and its `rules` rows could carry a later rule rename
     (`packages/basalt-ui/src/cli/migrate/rows.ts:49`).
4. **sync and doctor coverage.** `sync` refreshes the rules, skills, subagent, the AGENTS block and both presets
   (`packages/basalt-ui/src/cli/sync/render.ts:90-93`, `packages/basalt-ui/src/cli/presets.ts`). It does not refresh the hook, the hook entries or
   the token sheets. `doctor` covers everything `init` writes, in 12 checks, but it sends a missing hook entry to
   `sync`, which cannot fix it.
5. **Runtime.** The CLI runs on Bun only, and nothing declares that (P2-1).
6. **oxlint version.** The pin, 1.93.0, sits only in the generated preset settings. `init` installs exactly that
   version. `doctor` fails on any other version, patch bumps included. `lint` fails closed when oxlint prints no JSON
   (`packages/basalt-ui/src/cli/lint/engine.ts:138`). The seeded-offender check catches a plugin that loads but runs no rules. A
   consumer on a newer oxlint gets a red `doctor` and nothing else. There is no peer entry, so the package manager
   never warns.
7. **Other agents.** Only the AGENTS block reaches Codex or OpenCode, and it points them at `.claude/` and at slash
   skills. The hooks work in Claude Code only. The only place that says so is an internal doc that does not ship (P2-7).

## What is sound

- **One rule table.** `defineRules` and `mergeTables` reject a duplicate id, a form with no fix or fixture, a shared
  fixture, a bare denial message and anything over the ceiling. Presets, coverage blocks and the reference are all
  generated from it (`packages/basalt-ui/src/lint/rule-table.ts:96-190`, `packages/basalt-ui/src/lint/preset.ts`). No id is listed by hand.
- **Profiles and zones are data.** Ejected, seed, vendored and bespoke zones are switched off per form through the
  `formsOff` options. A bespoke directory is one named directory with no globs and not the root
  (`packages/basalt-ui/src/cli/manifest.ts:59-64`).
- **Tests per form.** Each form runs under two engines from one fixture file. The family tests assert form counts, the
  fix text and the profiles.
- **Waiver dialect.** A waiver must name its rule and give a `-- reason`. A placeholder reason is rejected and an em
  dash is caught. A file-level waiver is limited to 3 ids on `deepRender` paths. A blanket file-level disable is
  refused before the edit lands (`packages/basalt-ui/src/lint/weakening-edit.ts`).
- **Fails closed.**
  - The hook exits 2 on any failure, not 0.
  - The settings merge is byte-preserving and never drops a foreign command.
  - `lint` fails when oxlint or stylelint print no JSON.
  - `doctor` treats SKIPPED as a failure.
  - Check 8 runs a real probe in a shadow install, so it never touches the real roots.
- **The manifest parser** is strict, keeps unknown keys so a newer manifest survives an older `sync`, and writes
  canonical bytes.
- **The `sync` engine** guards each managed file by digest, skips local edits unless `--force`, three-way merges
  ejects and blocks, and `--check` works as a CI gate.
- **`basalt()`** fails the build on a missing peer or a stale seed, naming the command to run, and keeps
  `sources.css` generated and gitignored (`packages/basalt-ui/src/cli/init/steps.ts:740`).
- **The AGENTS block** no longer sends consumers to the factory. It now points at `bugs.url`, which closes that
  stock-take friction item.
