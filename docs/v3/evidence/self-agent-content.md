# self-agent-content: basalt-ui `./agent` + `./content` audit for the v3 rewrite

Scope: `packages/basalt-ui/src/{agent,content}` at master `6f1007a8` (2.29.x line). Paths below are relative to
`packages/basalt-ui/` unless they start with `~` or `docs/`. Fact = cited. Judgement = marked **[J]**.
Ecosystem facts researched 2026-11-09 via `agw research` (runs `01a1c068`, `01a1c06a`) and `agw web read` (tuffui.com).

## 0. Headline

1. **`./agent` has zero consumers.** argo deleted its Hermes chat on 2026-10-30 (`~/SourceRoot/argo` `0f5d0da3`
   `feat!: remove the Hermes chat…`, `92ca0939` "Hermes leaves Argo"); a grep of 11 fleet repos finds 0 files importing
   `basalt-ui/agent`. epos teamchat never took it (`~/IuRoot/epos-ai-teamchat-athena/ui/DESIGN.md` § "v3: basalt-ui, what we take":
   "`basalt-ui/agent` Not taken. It is an AI-SDK transport plus Mantine components") but copied its LOOK (DESIGN.md principles 10-12
   cite `tool-chip.tsx:40-189`, `thread-message.tsx:351-481`, `composer.tsx:211-617`).
2. **`./content` is used for 4 small things**: `Callout` (linewatch 7 files, rb, argo), `Prose`/`TableOfContents` (rb),
   `GuideLink` (linewatch), and the full `Markdown` + sanitize + fence registry only by basalt-ui-obsidian. software-factory console
   (shadcn + Base UI + basalt 2.29) uses raw `react-markdown` 10.1 and its own `.artifact-prose` CSS (`apps/console/src/components/artifact-content.tsx:1-3`).
3. **The code that is worth carrying is not the Mantine UI but the pinned laws**: part identity + offset-replay, the 7-state tool
   union, fail-closed sanitize/URL/image policy, settled-block memoization, fence "decline/contain" contract, StrictMode/Activity wedge fix.
   About 14k test lines (agent 10.4k, content 3.5k; 659 test cases) encode them. v3 must port the tests before the code.
4. **Biggest v3 opportunity is not in this domain's current code**: epos built an 8.7k-line (incl. tests) generative-UI `show` catalog
   (zod-schema'd stat/chart/table/diagram/vega/board blocks rendered from tool-call args). basalt has the seam
   (`agent/foreign.ts` `definePartRenderers`) but no catalog. That catalog IS the "wiring that makes components available to AI agents" in the brief.
