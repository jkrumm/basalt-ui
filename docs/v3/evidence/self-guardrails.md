# Evidence: basalt-ui's own guardrails (v3 rewrite input)

Snapshot 2026-11-09, basalt-ui 2.29.0, oxlint 1.90.0 installed. Paths are relative to `packages/basalt-ui` (PKG) unless prefixed `repo:`. **F** = observed fact with citation. **J** = my judgement. Counts are non-test `.ts/.tsx/.css` lines under `src/<dir>` unless stated.

## 0. Verdict in six lines

1. **J** The guarantee layer is the product's strongest asset. Mantine-free by construction already: charts, tokens, state, format (about 16k of 81k src lines), the derive engine, series check, budgets, agent-doc drift, layout-geometry suite, design loop.
2. **F** 16 of 27 guard kinds are disabled in the `tokens-only` profile because their remedy names a Mantine component (`src/guard/index.ts:1737`); 13 of 27 oxlint rules read Mantine tags or props (table 3b).
3. **F** The regex guard does NOT understand Tailwind. Probe `/tmp/probe-tw.ts` through `checkSource(..., DEFAULT_GUARD_CONFIG)`: `text-[13px]`, `bg-red-500`, `p-[13px] gap-[7px]`, `rounded-[7px] shadow-[0_0_3px_red]`, `md:grid-cols-3 max-[600px]:hidden` and `<h1>` all report `(none)`; `bg-[#ff0000]` reports `raw-hex` and `<input>` reports `raw-form-control` with a Mantine remedy.
4. **F** The software factory console (Tailwind 4 + Base UI + basalt tokens) runs with ZERO basalt lint: its `.oxlintrc.json` has no basalt entry, its DESIGN.md says the basalt-design "build laws do not [apply] (they are Mantine's)" (`repo:../software-factory/apps/console/DESIGN.md:35-36`), it wrote its own `test/no-raw-colour.test.ts`, and it has 34 arbitrary-value classes (42 `text-[...]`, 20 of them `text-[length:var(--vx-text-sm)]`) because the `@theme` bridge never mapped the type scale (`src/styles/index.css:15-45`).
5. **F** Waivers measure friction, not catches: 63 `theme-allow` comments in 10 consumer repos (39 shutterflow, 7 rb, 6 weatherorb, 6 image-gateway, 2 argo, 1 each linewatch/email-gateway/obsidian, 0 finances/rollhook); no rule records how many violations it caught.
6. **J** v3 should ship ONE engine (an oxlint JS plugin written in typed TS, bundled), a Tailwind-class rule family, types for everything expressible as a type, and keep the triad (surface registry -> rule bullets with enforcement tags -> generated coverage). Drop grace/retired-id machinery now.

## 2. Preset facts that matter for v3

- **F** `configs/oxlint.json:5-7` still ships `suspicious: warn`, `no-console: warn`; v2 audit guards-08 proposed error-or-off and is open. `PLUGIN_RULE_GRACE = {}` (`oxlint-plugin.js:4347`) and `GRACE_PERIOD_KINDS = {}` (`index.ts:907`) are empty, yet `check-grace.ts`, `grace.test.ts`, `RETIRED_RULE_IDS` (:97, 14 ids), `KNOWN_RULE_IDS` (:127) are maintained (guards-14 open).
- **F** Open from `docs/waves/maturation-v2/guards.md`: guards-04 plugin untyped JS (still JS), guards-15 five hand-synced id registries (`surfaces.ts:39`, plugin :127, `index.ts` `PLUGIN_RULE_IDS`, `oxlint-basalt.json`, test config), guards-02 rule prose claims more than guards check, guards-12 `[type X]` tag resolves but may have no `@ts-expect-error` test (17 of 42 tags at audit time), guards-23 hook scans edit fragments only.
- **F** oxlint `jsPlugins` are alpha, ESLint-v9-compatible, no custom parsers, no type-aware rules (https://www.oxcjs.com/guide/usage/linter/js-plugins.html, via `agw research` 2026-11-09). No built-in Tailwind plugin (https://oxc.rs/docs/guide/usage/linter/plugins).

## 7. (e) Slimmest v3 shape of the guardrail domain

### 7a. Shape

1. **One engine**: `basalt/*` oxlint JS plugin authored in TS (`src/lint/`), bundled to a dependency-free `configs/oxlint-plugin.js`; ids, preset, coverage and `KNOWN_RULE_IDS` generated from ONE rule table (kills guards-04/15, `WAIVER_ID_ALIASES`, retired list). Alpha-channel risk accepted (oxlint JS plugins alpha), with ESLint-v9 API as the fallback.
2. **One CSS/text scanner** for `.css`, `@theme`, `.html`, `.astro`, JSON manifests only (what AST cannot see): hex/rgb/hsl/oklch literals, `@media` widths, `unknown --vx-*`, `series-palette`, theme-allow grammar. Keep `tokens-only` as the only mode.
3. **Rule families** (target 20 rules, from 27 rules + 27 kinds):
   - tokens (T1-T3, T10, T12, `status-fill-as-text`, unknown-vx)
   - primitives (T5, T6, T9, `shadow-basalt-export` successor)
   - layout (T7, T8, `in-body-page-title`, `raw-scroll-container`)
   - controls (homes, only the residue types cannot express)
   - state/router (`search-literal-link`, `use-search-from-literal`)
   - charts (`chart-engine-boundary`, `chart-in-raw-surface`, `chart-host-single`)
   - platform (`route-view-transition`, `agent-no-raw-usechat`; repo-local: `no-dev-helper`, `no-import-meta-env`)
4. **Types first**: homes, actions budgets, typed-data slots, `variant`-only primitives (no free `className` on owned axes), branded series group, `Unwrapped<T>`, `Register`. Every `[type X]` tag needs a negative test (Check F2). Target: lint is the residue.
5. **Triad kept**: surfaces registry -> <=6 rule files, each bullet tagged -> generated coverage with honest `not guarded`; drift checks A-I minus the Mantine ones.
6. **Budgets kept**, re-baselined: symbols, rule lines, spec prose, bytes, plus new `waivers per kind` and `vendored-ui patches`.
7. **Verification kept**: layout geometry suite + hit floor, `shot` + detector + calibrated reviewer, `doctor` + `sync --check`. Add `shadcn add --diff` check (T9).
8. **Dropped now**: `check-theme-css.ts`, grace/retired machinery, `ai-sdk-major` + `basalt-agent-allow`, `forms-field-key`, Mantine-remedy kinds, isomorphic `NO_CLASSNAME`, fragment-scanning hook (replace by post-edit lint), five hand-synced registries.
