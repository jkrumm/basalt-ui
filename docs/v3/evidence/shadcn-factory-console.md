## 0. Headline

The Console imports **zero** basalt-ui code. It consumes exactly one artefact: the output of the `basalt-ui tokens:css` CLI (`package.json:10-11`, `Makefile:30`, `src/styles/tokens.css`). Everything else (shell, sidebar, palette, StatCard, Meter, charts, URL filters, live data) is a clean-room rebuild of concepts basalt 2.29 already ships, on shadcn base-nova + Base UI + Tailwind 4. The reason is a recorded decision, not a failed attempt: `../../docs/decisions.md:156` NL4 ("shadcn-style components on Base UI and Tailwind 4, with Basalt's colours, fonts, spacing and general feel. Basalt learns from it afterwards"). No commit or doc records trying a basalt component and abandoning it. So "friction with basalt" is not in git; the evidence is what was rebuilt, how, and where the rebuild is itself inconsistent.

## 6. Wiring extraction: router, query, SSE (what grew here)

**Data contract.** Every read is same-origin `/v1/*`, `fetch(..., {cache:'no-store'})`, parsed with a zod schema shared with the server (`@software-factory/contract`, 26 importing files); parse failure throws `ShapeError`, which means "server newer than this bundle": the global `QueryCache.onError` then calls `checkForUpdate()` and `retry` is skipped (`api.ts:34-60`, `queries.ts:33-44`). Non-2xx = `ApiError(status, path, detail)`. Writes: `postJson` with the API's own refusal words (`api.ts:100-112`). `failureNote(error)` turns the error class into page copy (`api.ts:62-67`).

**Query defaults** (`queries.ts:31-47`): `staleTime 5 s`, `gcTime 7 d` (must not be below snapshot maxAge, comment `:31`), `retry` once except `ShapeError`/404. Each read is a hook (`useNeeds`, `useFlow`, `useChain`, `useKpis(days)` …) of `{queryKey:[root,...args], queryFn:({signal})=>fetchX(signal), refetchInterval: pollEvery(live)}`; `select: withoutStamp` strips a per-response timestamp so structural sharing keeps the graph stable (`queries.ts:62-72`). First-screen queries are exported objects (`needsQuery`, `flowQuery`) so `main.tsx:21-22` can `prefetchQuery` in parallel with boot.
**Polling policy** (`policy.ts:4-9`): 15 s while the stream is down, 60 s safety while up (SSE keepalive is a comment `EventSource` cannot see). Strip readings (`accounts`, `machine`) are `POLLED_ONLY` (`policy.ts:40`) and poll regardless.
**Selective invalidation** (`policy.ts:68-110`): a frame `{kind, ref, issue?, detail?}` maps to the query roots it can alter: `BY_ROOT` table (needs/flow/chain by listed kinds; `issue` by number; `decision`/`artifact` by id); unparseable or unknown frame = invalidate everything except polled-only (conservative). Aggregates (`kpis, friction, finding-classes, fix-commits`) are a second class with a longer debounce.
**Debounce** (`debounce.ts`): trailing debounce with `maxWait` ceiling and an injectable scheduler (tests pass a fake clock); lists 250 ms / max 1 s; aggregates 2 s / max 10 s (`live.ts:16-21`).
**SSE client** (`live.ts`, 177 lines): one `EventSource('/v1/stream?since=<cursor>')`; `hello` event greets (first hello joins boot requests with `invalidateQueries(undefined,{cancelRefetch:false})`, later ones invalidate all), one listener per `CHANGE_KINDS` entry; cursor = frame `id` (`lastEventId`); `onerror` closes, drops the cursor if never greeted (how a 410 `cursor_gone`, invisible to EventSource, restarts), reconnects with 1 s doubling to 30 s (`debounce.ts` `nextBackoff`); `online` and `visibilitychange` reconnect; a 15 s watchdog tick that arrives >45 s late (sleep) or a tab hidden >45 s with no frame replaces the socket (`policy.ts:12-14,116`); `useSyncExternalStore` exposes `useLive()` and `useLastEventAt()`. **Server side** (`../../apps/server/src/read/stream.ts:1-28`): cursor `<txid>.<seq>`, emits only rows below `pg_snapshot_xmin` so resume loses/doubles nothing; `CursorGone` -> 410.
**Connection chip** (`connection.ts`): derives `Live | Polling | Offline - snapshot from <age>` from stream state + `navigator.onLine` + any errored query + newest `dataUpdatedAt` across the cache; `useSettle` disables writes while offline.
**Mutations** (`settle.ts`): `useMutation` wrapper taking `{send, keys, onSent, onConflict}`; refreshes list + detail on success and on 409 ("already settled", `onConflict`), maps refusals to words, exposes `{send, pending, disabled, error, reset}`; used 6x.
**Staleness vs deploys** (`update.ts`): `registerSW({immediate})`; re-check on visible, online, every stream `hello`, every 10 min, and on `ShapeError`; reload only when `safeToReload` (no focused field, no non-empty textarea). Config: `registerType:'autoUpdate'`, `generateSW`, `navigateFallbackDenylist [/v1/, /health, /frame]`, `cleanupOutdatedCaches` (`vite.config.ts:61-82`).
**Persist** (`main.tsx:24-44`): `PersistQueryClientProvider` + `createSyncStoragePersister(localStorage,'console-snapshot')`, `buster=__BUILD_ID__` (`vite.config.ts:46`), dehydrate filter drops `artifact`/`issue`.
**Time**: `useNow(30_000)` ticks one shared `now` into cards so ages stay fresh without refetch (`lib/now.ts`); `ageWords` is a 10-line local formatter, not `basalt-ui/format`.
**Generic vs app-specific [J]**: generic and liftable into a v3 `./live` module = `trailingDebounce`, `nextBackoff`, watchdog/visibility logic, the `useLive` store, `pollEvery`, persister+buster setup, `ShapeError -> update` hook, `useSettle`, `safeToReload`. App-specific = the `BY_ROOT` map, `CHANGE_KINDS`, the cursor format. The seam is a `(frame) -> predicate(queryKey)` function.
