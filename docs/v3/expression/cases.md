# Expression case bank

Each case states a viewer, a question and data. It names no chart form on purpose. A builder gets one case verbatim and authors a seeded fixture of the stated shape. Protocol: `docs/v3/EXPRESSION.md`.

`ran` is the cycle that used the case. A case runs once.

| Id  | Viewer and question                                                                                                                           | Data                                                                                                             | ran |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | --- |
| c01 | An engineer watches a three-stage pipeline run. Is this run on pace against the best run, and which stage is costing or saving time?          | Stages in order with a best split each; splits for finished stages; elapsed seconds; the run may still be going  |     |
| c02 | An on-call engineer opens webhook deliveries. Which endpoint is failing, since when, and is it a volume problem or a failure problem?         | 8 endpoints by 24 hours: attempts and failures per cell                                                          |     |
| c03 | A service owner checks one tool. Are we inside the SLO for the last 24 hours, and by how much?                                                | Total calls, failed calls, an SLO target in percent                                                              |     |
| c04 | A performance engineer reviews agent run durations. What is typical, how bad is the tail, and how many runs hit the timeout?                  | About 300 run durations in seconds, a timeout value; some runs end exactly at the timeout                        |     |
| c05 | A legal ops lead plans the year. Which contracts need a notice soon, and which renew on their own?                                            | About 12 contracts: renewal date, notice deadline, auto-renew flag, annual value                                 |     |
| c06 | A user of a coding agent glances at the context window. How full is it, what fills it, and when should I compact?                             | A token limit, four categories with token counts, a warning threshold at 80%                                     |     |
| c07 | An ML engineer reads an eval run. Did this run beat the baseline, and which cases changed sides?                                              | 60 cases: pass or fail now, pass or fail in the baseline; input, expected and actual per case                    |     |
| c08 | An engineer debugs one slow agent run. Where did the 8 seconds go, and which step failed?                                                     | A span tree: name, start, duration, kind (model, tool, retrieval), status, tokens                                |     |
| c09 | A release owner compares deployed versions. Which version hurt quality, and what is live now?                                                 | 5 versions with deploy times, one rolled back, one live; a quality metric sampled over time                      |     |
| c10 | A security responder handles a leaked key. What can this key reach, and how many steps away is each resource?                                 | A graph of about 20 resources of six kinds, edges, the leaked key as origin, an affected flag                    |     |
| c11 | A retrieval engineer tunes a cut-off. How many chunks does the cut-off keep, and where does the mass of scores sit?                           | 2,400 chunks with two scores each (relevance, recency), a relevance cut-off                                      |     |
| c12 | A team lead checks AI spend. Are we inside this week's budget, and which model drives the cost?                                               | Daily cost per model for 14 days, the current day partial, a weekly budget                                       |     |
| c13 | A SOC lead reviews triage. How much did automation close without a person, and on which days did escalations spike?                           | 30 days: alerts closed automatically by five sources, alerts escalated to a person                               |     |
| c14 | A researcher watches five models run the same 400-case eval suite live. Who leads, by how much, and how far along is everyone?                | Per model: cases done, cases passed, a live rate; the suite size                                                 |     |
| n01 | A household checks its internet line. How often did the line drop in the last 30 days, for how long, and does speed hold the contracted rate? | Outage intervals, hourly down and up speed samples, a contracted rate                                            |     |
| n02 | The factory owner opens the console. Where are Issues stuck, and for how long?                                                                | About 30 open Issues: stage (queued, building, review, deploy, verify), time in stage, a typical time per stage  |     |
| n03 | An athlete plans the week. Is this week's training load inside the target band, and how does it compare with the last eight weeks?            | Daily load for 9 weeks, a weekly target band, planned sessions for the rest of this week                         |     |
| n04 | A cyclist decides when to ride in the next 48 hours. Which windows are dry and calm enough?                                                   | Hourly precipitation probability, wind speed and temperature for 48 hours; personal thresholds for rain and wind |     |
| n05 | An engineer picks a model for a workload. Which models give the most quality for their price, and which is beaten by a cheaper one?           | About 25 models: price per million tokens, a quality score, a family; several families come in three sizes       |     |
| n06 | A user on a usage-capped plan checks the current window. Will the quota run out before the window resets, and when?                           | Cumulative usage in percent sampled over the current 5-hour window, a few sudden jumps; now; the reset time      |     |
| n07 | An amateur astronomer plans the next ten nights. Which night is best, and why is each other night ruled out?                                  | 10 nights: dark hours (0 if none), go, marginal or out, one limiting factor per out night, a target altitude     |     |
| n08 | A lifter decides on today. Given recovery and the planned load, should I train, and how often has this pairing come up?                       | Recovery (low, normal, high) by planned load (light, moderate, heavy): verdict and past days per pairing; today  |     |
| n09 | The factory owner checks the schedule. What runs next, when, and what is already beyond the next 24 hours?                                    | About 15 scheduled jobs: name, next run time, recurrence, owning repo; some next runs fall past 24 hours         |     |
| n10 | A sailor compares forecast models before a passage. Do the models agree on the wind for the next 72 hours, and where do they part?            | 4 forecast models: hourly wind speed, gust and direction for 72 hours; an ensemble 10-90 percentile band hourly  |     |
| n11 | A learner browses a course catalogue. How hard is each course, and how far along am I in the ones I started?                                  | About 20 courses: difficulty 1 to 5, lessons done and lessons total (0 done for most)                            |     |

Every build covers: loading, empty and error; a zero or extreme value from the fixture; light and dark; 1800x1200 and 390x844; keyboard reach.
