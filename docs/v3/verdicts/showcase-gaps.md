# Showcase gaps

Built with the playground's Kit gallery (`apps/playground/src/routes/kit/`, nav group Kit), from owner review 1 on
2026-11-18. Each row is a place where the shipped surface could not do what a Kit page needed. None is built around:
the page leaves the part missing (or shows the nearest shipped form) and this list names it. Nothing here is filed;
the list is for the owner. One capability of the brief is not in the gallery at all: resizable panes (the first
row), because the shipped part fails the quality matrix and neither a restyle nor a waiver may route around it.
