# Keel route index

Look-only capture of `https://keel-workspace.vercel.app` (no source, no licence). Screenshots only; see the licence boundary in `docs/waves/PLAN.md` Part 3. Captured by `scripts/evidence/keel-capture.ts`; patterns in [`inventory.json`](inventory.json), scales in [`../BENCHMARK.md`](../BENCHMARK.md).

Each route is captured at 1440x900 (desktop) and 390x844 (mobile, touch), device pixel ratio 1, reduced motion, in the dark and light schemes. Keel's account menu has a system/dark/light scheme choice and follows the emulated scheme, so both schemes are real. Per combination there is one viewport shot and one `--full` shot (the shell scrolls an inner container, so the viewport is grown to the content height, capped at 3600 px).

## Not captured

- Loading state (unverified): navigation inside the app is instant and no skeleton or pending state could be observed, even with the network throttled; the inventory records it as unverified (could not be observed, not proven missing).
- Overlays (command palette, account menu, notification panel, row menus) were opened only to read the scheme options, not captured.
- Per-column scrolling inside the kanban columns: only the first screenful of each column is in the full-page shots.
