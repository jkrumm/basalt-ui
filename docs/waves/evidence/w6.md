Reproduce the v9 numbers with
`make evidence LABEL=<label> LANES=table-perf` on the merged tree and compare the `over control` rows
against the baseline file above. The lane and its `/table-perf` fixture import `basalt-ui/table` only, so
the same route measures both.

A `LANES=` run never replaces the full summary: it writes `docs/waves/evidence/w2/<label>.table-perf.md`
(headed "Partial run") beside it, and raw JSON to `.evidence/<label>/` (gitignored). The committed
baseline is that file's table, moved here.
