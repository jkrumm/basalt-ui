# basalt-ui 2.0 — surface verdicts (1.41 → 2.0)

Wave 3's deletion checklist and the source for `MIGRATING.md` § 2.0. One row per 1.41 export (value
and barrel type), per subpath: a name re-exported from two subpaths has two rows. Contract:
`docs/V2-SPEC.md` § 1. Method and counts: `docs/waves/evidence/w1/core.md`.

- **Verdicts:** `keep` · `move→<2.0 subpath>` · `delete` · `→ § 9` (chart layer, owned by the
  v2-charts lane). A `move` changes only the import specifier; the name is unchanged.
- **Consumers:** files outside `apps/playground` importing the name from that specifier, across
  argo, linewatch, weatherorb, rb, rollhook, basalt-ui-obsidian, email-gateway and image-gateway
  (`count — first repo:file`). `—` = none.
- **Defaults** (reason column blank or generic): a used export keeps its name and maps to its 2.0
  subpath; an unused value is deleted (charter point 1); an unused type is deleted (derive it with
  `ComponentProps<typeof X>` / `Parameters<typeof f>[0]`); a duplicate re-export is deleted, or moved
  to its canonical home when a consumer imports it from the duplicate path.
