# RadioGroup

A group of radios on Base UI: one selected value, arrow keys move it in DOM order. Works with no
provider and joins a Base UI `Field` when wrapped in one. Name each radio with a wrapping
`<label>`.

## `radioGroupVariants`

Part `radio-group`.

No variant axes.

## `radioVariants`

Part `radio`.

No variant axes.
