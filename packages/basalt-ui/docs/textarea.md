# Textarea

A multi-line text field on Base UI's `Input`, rendered as a `<textarea>`. Height is the fixed
`rows` (default 3). Works with no provider and joins a Base UI `Field` when wrapped in one.

## `textareaVariants`

Part `textarea`.

No variant axes.
